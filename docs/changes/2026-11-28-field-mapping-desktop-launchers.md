# 建图步骤改为桌面程序入口

日期：2026-11-28

## 目标

将 NUC 桌面 **建图与中心点** 文件夹中直接显示的 Shell 脚本替换为带名称和图标的应用程序入口，使现场人员可以双击运行每一步。

## 变更

- 为步骤 00～09、红方出生点 06A 和蓝方出生点 06B 新增 `.desktop` 程序入口。
- 原始 Shell 脚本安装到隐藏目录 `/home/rm/Desktop/建图与中心点/.scripts/`。
- 安装时把旧的桌面顶层 `.sh` 移入带时间戳的隐藏备份目录，不直接删除。
- 程序入口使用原有安全脚本，不改变建图、定位或出生点记录逻辑。
- 保持 `enable_drive=false`、`enable_autoaim=false` 和 `start_navigation=false` 等既有安全设置。

## 使用方法

打开 NUC 桌面的 **建图与中心点** 文件夹，按编号双击程序图标。首次显示系统确认时选择 **允许启动**。程序会自动打开终端显示执行结果。

红方和蓝方出生点分别使用：

1. **06A 选择红方出生点**
2. **06B 选择蓝方出生点**

本次只调整桌面入口和文档，不修改 ROS 2 节点、导航参数或底盘控制逻辑。
