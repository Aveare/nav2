# 硬件识别与资源配置规范

## 1. 配置依据

本文件提供设备识别和配置检查项，不构成已确认 BOM。设备选择以实际产品版本、机械负载和用户设计为依据；绑定前核对 `.ioc`、原理图/接线表、设备设置及厂商协议，按 [设计输入](design-intake.md) 记录。

## 2. 主控与 C 型开发板

随包固定提交的构建和链接脚本面向 STM32F407IG 系列/F407IGHx。C 型开发板及 BMI088 是常见适配方向，工程包含相应模块；仍需确认实际板型/修订、MCU、时钟/引脚、传感器启用状态、板间分工、接口和工具链。

电源、电压、共地、CAN 终端及电机分电按实际硬件资料核对。保留上游 `.Doc/必须做&禁止做.md` 的供电约束；开发板接口不能作为未经确认的电机分电方案。

## 3. 候选设备及适配项

下列用途为工程参考，不限定兵种配置。

| 候选 | 常见用途 | 关键适配项 |
| --- | --- | --- |
| M3508 + C620 | 轮驱、摩擦轮等 | 电调/编号、传动比、控制与反馈单位、负载 |
| M2006 + C610 | 拨弹、小型机构 | 步距/传动、负载、编号、堵转与恢复 |
| GM6020 | yaw/pitch 等 | 产品/固件、控制模式、机械轴、编号、零位/限位 |
| DM/HT/LK 等智能电机 | 腿部、机械臂、转向等 | 完整型号/模式、控制/反馈 ID、范围、使能/回零协议 |
| PWM 舵机、步进、阀/泵 | 盖板、夹爪、升降等 | 驱动电气接口、通道/定时器、原点/行程、失电状态 |
| 摄像头、雷达、测距/定位 | 视觉、导航、定位等 | 采集/处理端、坐标/标定、时间戳、电控数据接口 |

适配现有 Module 前核对其 `.h/.c/.md`。无对应支持时依据厂商资料补充协议实现；增加枚举值不能代替驱动开发。

## 4. CAN 编号语义

分别记录设备设置编号、控制帧 ID/组帧槽位、反馈帧 ID。必要时增加主机 ID、模式偏移和协议版本。

本基线 DJI 初始化的 `can_init_config.tx_id` 表示电调编号，由 `MotorSenderGrouping()` 计算控制帧及槽位；不能按字段名称将其直接填写为组帧 CAN ID。不同电机型号的反馈偏移和控制组可能交叉，必须对照具体驱动及协议。

同总线检查：

- 接收标识是否重合，过滤与回调是否匹配。
- 控制组帧及槽位是否重合，组帧发送是否只有明确的所有者。
- 波特率、周期、负载及重发/拥堵处理是否符合系统需求。

不得自动递增相邻电机 ID 或预设 CAN1 的机械归属。首次反馈、在线状态、位置映射和正方向分别验证。
