# 硬件与协议速查

> 只放"硬件事实"，不放下一个兵种的接线结论。具体接线/ID/方向以
> `.Doc/robots/<robot>/README.md` 与 `config/<robot>_2026/` 为准；本文件用于快速核对协议与量纲。
> 内容来源：现行代码与 2026-11 前的实测记录（证据见开发史附录 I）。

## 1. 主控与板型

- MCU：STM32F407IGHx，单板 `ONE_BOARD`（双板分支未实装，profile 守卫会 `#error`，DEC-009）。
- 时钟/时基：DWT 由 `board_port.h` 初始化；逻辑层用 `kernel_tick_ms/us`，不用 `HAL_GetTick`。
- 调试：SWD；RTT 走 `log_port`；烧录 DAP/JLink 由 `tools/flash_manual.ps1` 或 EmberProbe。

## 3. DJI 电机协议

- 组帧（拨码号 ≠ 帧 ID）：M2006/M3508 `id1-4 → 0x200`、`id5-8 → 0x1FF`，反馈 `0x200+id`；
  GM6020 `id1-4 → 0x1FF`、`id5-8 → 0x2FF`，反馈 `0x204+id`。
- 反馈：`ecd` 0~8191（机械角 8192/圈）；`speed_rpm`；`real_current`；温度。
- 减速比：M3508 19:1；M2006 36:1；GM6020 直驱。
- 多圈角：跨 4096 判断方向累加，掉电不保留（需要持久化用 `calib` Flash）。
- 电流/电压帧：同一 ID 不能混发两种帧；模式切换必须在配置里显式选。

## 4. 达妙 DM 电机（MIT）

- 8 字节 MIT 帧：`pos(16) vel(12) kp(12) kd(12) torque(12)`，单位按驱动器量程换算。
- `Kp=Kd=0` 时是纯力矩模式；力矩量程与 `torque_min/max` 每实例配置。
- 反馈带状态位：过压/欠压/过流/MOS 过温/线圈过温/通讯丢失/过载；应用层必须检查状态与新鲜度。
- 失能后需重新使能；`rearm_required` 逻辑见 `apps/sentry/gimbal/gimbal.c`。

## 5. 海泰 HT04 / 舵机 / 其他

- HT04：CAN 线序与常见相反；报文小端；`pos-vel-Kp-Kd` 置零要按手册；编码器需校准。
- 舵机：PWM 50 Hz，脉宽 500~2500 µs 对应 0~180°（按型号核对）。
- 超级电容：0x301 控制、0x302 反馈（4×uint16）；当前未装（OPTIONAL）。
- CAN 总线：1 Mbit/s；两端各 120 Ω 终端；支线尽量短；过滤器数量受 bank 限制。

## 6. 遥控 DBUS

- 帧长 18 字节，通道偏移 0/11/22/33/44，每通道 11 bit；`s1` 左右拨杆 1~3 挡。
- 鼠标：x/y 各 16 bit、左右键、中键；键盘位域见 `remote_control.c`。
- 失联检测由驱动层给出；逻辑层失联 → 零力（`SENTRY_AUTH_RC_LOST_STOP`）。

## 7. 裁判系统

- USART6 115200 8N1；帧头 `0xA5`，长度/序号/CRC8 帧头 + CRC16 帧尾。
- 常用命令：`0x0201` 机器人状态（热量上限/冷却/等级）、`0x0202` 功率与缓冲能量、
  `0x0204` 发弹量、`0x0208` 允许发弹量、`0x0302` 自定义交互、`0x0503` 视觉下行。
- 2026 协议：`0x0202` 仍有电压/电流/功率字段（代码按 14 B 解析）；但控制侧不再依赖功率反馈。
- UI：字符串名/图层/批量刷新有上限；改 UI 先核对 `referee_ui.c` 的发送频率与重发策略。

## 8. BMI088

- SPI 读需 16 bit 事务（首字节带读位，第二字节起有效）；加速度计首次读为无效值（假读）。
- 中断读取走非阻塞；加热器 PWM 由 `imu_port` 控制；姿态解算在 `ins_task`（1 kHz）。
- 无磁力计 → yaw 无绝对参考，只能陀螺积分。

## 9. 量纲约定

| 量 | 单位 | 备注 |
|---|---|---|
| 底盘速度 | mm/s | 内部；ROS 侧 m/s（见导航协议） |
| 云台角度 | rad（代码）/ deg（配置名） | 配置宏名带 `_DEG` 的是角度 |
| 电机转速 | rpm（反馈）/ aps（部分内部） | 换算见 `chassis_kinematics.c` |
| 电流 | 原始码值 / 1000（功率模型） | 功率模型 `i=current_cmd/1000` |
| 时间 | ms / us | `kernel_tick_ms/us` |
