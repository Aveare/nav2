# AI 协作约束规范

## 1. 目的与证据

本工程以 AI 为主要开发者。AI 的失效模式高度可预测，圈内开源实践已收敛出对策：

| AI 的病 | 表现 | 对策 |
| --- | --- | --- |
| 猜硬件 | 凭空猜引脚/寄存器/工程结构，编译能过、板子是乱的 | 板卡/框架知识固化为本 skill 与代码地图；寄存器级内容必须人工核对 |
| 过度防御 | 自建状态锁、看门狗、诊断结构、"更安全"的包装层 | 否决台账 + 授权分级 + 审计红旗 |
| 越界重构 | 借小任务重写模块、新增文件与任务 | Boundaries 禁区 + 基线审计增量比对 |

依据来源（核查日期 2026-10-27）：[AGENTS.md 开放标准](https://agents.md)（Map→Boundaries→Checks→Evidence 四段式，60k+ 项目采用）；立创开发板公众号《电赛四天三夜，怎么让 AI 提效辅助得更准更快？》（AGENTS.md+Skill 减少"猜"）；[mspm0-skill](https://github.com/Ibook000/mspm0-skill)（AI 烧板教训：价值在定义正确规范）；[nuedc-engineering-skill](https://github.com/DushsK/nuedc-engineering-skill)（约束幻觉、无意义防御、记录生成模型）；《嵌入式开发中的"AI病"》（CSDN，先AI→再编译→再板级三级验证）；电赛备赛指南"三用三不用"（ISR/寄存器配置/多模块时序不交 AI 裸写）。

## 2. 五层约束模型

| 层 | 机制 | 职责 |
| --- | --- | --- |
| L0 意图 | 本 skill 全部规范 | 大方向 |
| L1 合同 | 工程根 `AGENTS.md`（按 agents.md 标准） | 每次会话自动生效的工程级契约 |
| L2 工具 | hooks 拦截 + `audit_baseline` 红旗检测 | 机器强制，不靠自觉 |
| L3 审计 | 交付前基线审计，DEV 条目引用审计结果 | 改动可追溯 |
| L4 流程 | 授权分级 + 中断前写记录 | 越权动作先问人 |

## 3. AGENTS.md 内容要求

按四段式维护，**保持简短、可执行、随赛季更新**（过期的规则比没有更糟）：

1. **Map**：基线身份与只读快照位置、代码地图入口、关键文件、本车配置速览。
2. **Before editing**：会话开始三步——读 `RM_DEVLOG.md` 冷启动摘要 → 跑基线审计 → 对受影响文件做基线 diff 预期。
3. **Boundaries**：禁改目录（生成代码/第三方库/构建脚本）；默认禁改层（components/framework/ports 接口需最小修复+批准）；结构级变更需批准（新增 C/H、新函数、新任务、新消息字段）；禁止 `while(1)` 错误处理与已被否决的自建设施；逻辑层（apps/components/framework）禁触硬件句柄；framework 零 RTOS include；未授权不编译不烧录。
4. **Checks + Evidence**：可复制的检查命令；交付证据要求（DEV 条目 + 审计结果 + 未执行项声明）。

写法三铁律：写具体命令不写抽象建议；禁区清单化不写"保持整洁"；每条规则要么改变一个动作、要么产生可检查的证据，否则删掉。

## 4. 会话协议

**开始三步**：读冷启动摘要 → 基线审计 → diff 预期。
**结束三步**：写 DEV 条目（注明 AI 协助与模型名）→ 更新决策/否决台账 → 重跑审计并记录结果。

**授权分级**：参数级（robot_def/config 数值、PID、ID、方向、注释）可直接改；结构级（新增文件/函数/任务/消息字段、改调用链、改 components/framework/ports 接口）必须用户对**该次操作**明确批准，已有授权不重复询问但不自动扩展。

## 5. 决策与否决台账

被否决的方案必须记入工程主记录的 DEC 台账（编号 `DEC-NN`：决策/理由/被否方案/日期）。理由：AI 会话无状态，未记录的否决会在后续会话中被原样重新提出。台账由用户或会话按 [工程记录规范](development-handoff.md) 维护。

## 6. 日志优先级

日志第一读者是 AI（会话无状态，冷启动只靠仓库文件），第二读者才是人。因此：工程日志结构化、带稳定锚点（DEV-YYYYMMDD-NN / DEC-NN）；运行时日志双通道——AI 通道为纯 ASCII 结构化行（`[ms][comp][lvl] key=value`，可 grep，错误入环形缓冲），人通道保留彩色 LOGERROR 与声光提示；构建/测试日志保留完整命令与退出码，AI 读全文、人看结论。
