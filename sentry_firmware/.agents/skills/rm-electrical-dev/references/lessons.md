# 历史踩坑与铁律

> 从 218 条 DEV 条目与开发史附录 B 提炼。每条都对应一次真实故障；改代码前先扫一遍，
> 完整证据按编号查 `.Doc/history/开发史.md` 附录 I。

## 1. 通信与中断

- **串口接收必须"循环 DMA + 任务消费"**：早期空闲中断+单次 DMA 会进入"半死态"（中断还进、数据不来），
  修复见 DEV-20261121-04/-06。现在 `ports/stm32f4/usart_port.c` 用循环 DMA，任务侧消费。
- **错误中断必须清标志**：ORE/FE 不清会在错误中断里反复重入，把急停指令饿死——
  "急停失效"的真因是错误中断风暴（DEV-20261121-05），不是按键。
- **解析禁止递归**：分包重同步写递归会在最坏输入下打穿任务栈，随后 HardFault 死循环
  （DEV-20261121-08）；改为滑动窗口/状态机。
- **CAN 发送非阻塞**：每总线 FIFO 满时丢最老并计数；不要在控制任务里等邮箱。
- **消息深度 1**：只保最新帧，事件型消息不得依赖排队；`msg_publish` 禁止 ISR 调用。

## 2. 日志与工具链

- **`%f` 禁令**：SEGGER RTT 的 printf 不支持浮点，`%f` 会让可变参数错位并最终 HardFault
  （DEV-20261121-10）。浮点先 `log_float_to_str` 再用 `%s`；`tools/check_log_format.ps1` 守卫。
- 给 AI 读的日志用纯 ASCII 结构化行（`[ms][comp][lvl] key=value`），人读的用彩色/中文；
  不要把中文标记塞进 grep 依赖的字段。
- **PowerShell 5.1 读 UTF-8 会按 ANSI 解码**：统计中文文件必须 `-Encoding utf8`；
  新增 `.ps1` 注释一律 ASCII（无 BOM 中文可能被 GBK 解析成续行反引号）。
- 工具输出要带结论与退出码；"人肉读屏"不算验证。

## 3. 时间与调度

- 逻辑层禁用 `HAL_GetTick`，统一 `kernel_tick_ms`/`kernel_time_us`；ISR 内用 `*_FromISR`。
- 禁止在 apps/components 直接调 FreeRTOS/CMSIS-RTOS；任务创建/延时/临界区走 `framework/kernel`。
- 周期任务的 dt 要防异常（0 或过大），按上限截断，否则斜坡/积分会跳变。
- 运行期错误不得 `while(1)` 挂死；启动期 fail-fast 例外见 `.Doc/gate/redflags`。

## 4. 功率（2026 协议无功率反馈）

- 2026 协议删除了功率反馈字段，只能用**电机模型预测**：四轮求和
  `P=Σ[K0+K1|i|+K2w+K3|i|w+K4i²+K5w²]`，再解二次方程求 scale。
- 模型必须**实测标定**：RTT `[pwr]` 流 → `rtt_pwr_to_csv.py` → `fit_power_model.py`；
  保留 304 形状、只调 `MODEL_SCALE`（DEV-20261126-34）。
- 总 scale 永远作用于四轮电流，floor 0.20；`ss` 只压自转压不住总电流（DEC-016）。
- 降额同拍生效、恢复按 `POWER_SCALE_LP=0.15` 一阶低通；缓冲衰减只在收到 `0x0202` 后生效，
  裁判离线不得衰减（否则 80 W 被砍到 40 W）。
- **哨兵当前没有功率模块**（只在 infantry 编译）；不要把步兵功率结论当成哨兵已实现。

## 5. 云台

- yaw 无磁力计 → 无绝对参考，长期漂移是硬件现状；不要用"加磁力计"当软件修复。
- 重力前馈必须拟合（角度-力矩多点），拟合前先确认反馈角是"合成角"还是"电机轴角"；
  当前哨兵 pitch 用的是解锁点相对电机轴角，重力前馈 A/B=0 未启用。
- 双 yaw 分配是纯函数（`gimbal_alloc.h`），生产代码未调用；改分配律先补主机测试。
- 达妙 MIT 反馈要同时看状态位（过压/过流/过温/通讯丢失）与新鲜度；失能后 `rearm_required`。
- 小陀螺（ROTATE）时大 yaw 目标是世界角速度 0（保持相对静止），不是角度回正；
  小 yaw 的限位与中位是电气相对量，换车必须重标。

## 6. 发射与热量

- 单发/三发必须走**角度环 + 逐发停车**；只给速度会多发（DEV-20261124-01）。
- 摩擦轮两轮到速互锁 fail-closed：单轮掉线时不许发射，不要把"台架旁路宏"带进正式固件。
- 堵转判据 = 转速低 + 电流高 + 持续时间，三条件缺一都会误判/漏判；锁存后只能 STOP 清。
- 热量守卫：反馈只校正 Q̂，记账点在放行瞬间，误差只允许往安全方向；
  两级闸门（连发余量 30 → 单发 10 → HOLD）；`ALLOWANCE_ENABLE` 正式比赛前必须置 1。
- 冷却按 `q -= cooling·dt` 连续扣，不是 100 ms 阶梯；断流 300 ms 只降级记录，不直接压射速。

## 7. 流程

- **编译通过 ≠ 闭环**：实体故障只有实车/台架确认才能关闭。
- **先取波形再改参数**：无遥测支撑的盲改会被回滚（DEC-004）；一次只改一个变量。
- **DEV 编号撞过号**：多设备并行时 `-NN` 会重复（36/37 与 38），已改 `DEV-YYYYMMDD-HHMMSS`。
- **同一事实只写一处**：文档漂移比没文档更糟；兵种专属结论放 `.Doc/robots/<robot>/`。
- 被否决的方案必须入 DEC，否则后续 AI 会话会原样重提。
