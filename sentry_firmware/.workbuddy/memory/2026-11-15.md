## skill 读底盘参数:跑通,但踩了两个工具限制（13:50）

**结论:`.agents/skills` 直连可用（不走 MCP），但 `variables.read` 读不了电机结构体字段。**

### 限制 1：`variables.read` 不支持复合类型 / 指针解引用
- 本工程 ELF 经 **LTO** 后，复合类型布局在 DWARF 里不可用：
  `chassis_feedback_data.vx` → `INVALID_VARIABLE_PATH`；
  `motor_lf->measure.speed_aps` **不报错但返回垃圾**——它把 `->` 当成"指针变量自身 + 字段偏移"，
  报的地址 `0x2000E8B0` 恰好就是 `motor_lf` 这个**指针变量**的地址（真值 `0x20011CA0`）。
  **静默错值比报错更危险，以后不要用它读 `->`。**
- 实测只有**顶层标量**可靠：`est_vx/est_vy/est_wz`、`vt_lf..rb`、`chassis_vx/vy`、`chassis_last_ms`、`motor_lf`(指针本身)。
- 单次上限 **32 个字段 / 4096 字节**，超了返回 `LIVE_READ_BUDGET_EXCEEDED`。

### 限制 2：`memory.read` 必须在**暂停**的会话里
- 无会话 → `DEBUG_SESSION_NOT_ACTIVE`；运行态 → `Pause the debugger before inspection`。
- 流程：`debug.js --start --attach`（halt，不复位不重烧）→ pause → memory.read → continue → `--stop`。
- 范围限 `0x00000000-0x3FFFFFFF`，单次 ≤4096B。

### 关键事实修正：`motor->feed_cnt` 不是帧计数
`dji_motor.c:155` `motor->dt = DWT_GetDeltaT(&motor->feed_cnt);` —— 它存的是**上次反馈的 DWT 时间戳(µs)**，
32 位约 **71.6 min 回绕**（头文件注释已写"会溢出的 DWT 计数不能作在线判据"）。
→ **在线判据改用 `dt`**：`dt = DWT_GetDeltaT` 结果（距上一帧的时间），**<5ms 即在持续收帧**；单次采样即可，不必两次比对。
→ `feed_cnt/1e6` = 开机秒数（本次 1406s ≈ 23.4 min，与两次读数差吻合）。

### 结构体偏移（`arm-none-eabi-gdb -batch -ex "ptype /o ..."`
`DJI_Motor_Measure_s`：last_ecd +0(u16) / ecd +2(u16) / angle_single_round +4(f32) / **speed_aps +8(f32)**

## 手推实测两次:自转法不可用,直线法读数 1434mm/2000mm 待澄清（13:50）

### 试验 1:手推原地自转一圈(失败,方法本身不可用)
- 活动段 22.6 s,平均 |wz| 36.5 deg/s,峰值 62.9,积分 **833.9°(2.32 圈)**;平移漂移 vy 积分 **467mm**。
- 用户答"没数清" → 缺真值。但更根本的问题:**麦轮原地自转辊子横滑 10~20%**,
  而力臂验收要求 <10% → **方法分辨率低于被测误差,自转法不能用来验力臂**。
- 结论:**力臂 340mm 取几何值 √(250²+230²)=339.7mm 即可**,不需要自转验收(它由 WHEEL_BASE/TRACK_WIDTH 决定,两者已实测)。
  真正该实测的是**轮径**(进 WHEEL_RATIO,影响全部速度换算)。

### 试验 2:手推直线 2m(用户:有轻微左右摆头)
- 活动段 3.94 s(vx 峰值 653mm/s,均值 364),积分 **X=+1434mm**,Y=+19mm,**航向 +0.2°**
  → **摆头几乎无影响**(cos 误差 <0.1%),数据本身是干净的。
- 但 1434 vs 2000 = **0.717**,差 566mm。
- **反证几何不是元凶**:若真值确为 2000,则实际轮半径须为 104.6mm(直径 209mm),与实测 150mm 差 39% → 不可能。
  → 只剩两种解释:①实际没走满 2m(约 1.4m) ②推得快、轮子打滑(车比轮子走得快)。
- 待用户确认车实际停位/复测 1m 慢推(约 0.2m/s)。

### 方法论沉淀
- 手推法必须**慢**(≤0.2m/s)且确认**轮子真在滚不打滑**;推车越快,齿轮箱阻力越容易让轮子拖着走。
- 用 `est_vx` 积分验轮径的前提是"无滑移",否则量到的是滑移率而不是几何。

## 底盘运动学代码核对(13:56):无 bug,但 0.7071 一物两用

正解 `MecanumCalculate` 与逆解 `EstimateSpeed` **严格互逆**(乘 0.7071 / 除 0.7071),

1. 辊子 45° 因子(作用于 vx/vy 项);

`0.70710678f` 目前是**裸魔法数出现 8 次**(正解 4 + 逆解 4),按 `注释规范` 应提具名常量。
