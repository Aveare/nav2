## 鼠标摇杆化手感（DEV-20261102-03）

- 冲感根因：鼠标是位置型输入（单帧位移直加目标角），甩一下目标跳几十度，云台满速追。
- 柔化两级：KBM_INPUT_LP=0.35（增量低通）+ KBM_MAX_DEG_PER_CYCLE=0.6°（≈120°/s 转速上限）。
- 调参档：仍冲→LP 0.2/上限 0.4；肉→LP 0.5/上限 0.9；准度→调 Client 灵敏度，别动 LP。
- 通用认知：**鼠标（位置型）想接近摇杆（速度型）手感 = 输入低通 + 目标变化率限幅**，不是单纯降灵敏度（降灵敏度只改变总位移比例，不改变瞬时冲感）。

## 鼠标曲线映射（DEV-20261102-04）+ 开源对比

- 开源对比结论：UT-RAS 鼠标→云台=位置型+可配灵敏度，摇杆用 quadratic 映射，键盘底盘用固定加减速率做惯性；2025 热门是云台 SMC 滑模（复旦/川大开源，架构级替换，记为赛季后选项）。
- 本车已实现：低通 + 单周期限速 + 曲线增益（三项均超过多数开源实现）。
- 曲线公式：gain = 1 + QUAD×(|原始mouse|/SCALE)，上限 MAX；乘法实现无 pow；增益用低通**前**的原始手速算，作用于低通**后**增量。
- 调档：转身慢→QUAD 1.5/SCALE 35；瞄准跳→QUAD 0.5/SCALE 70；线性→QUAD 0。

## 小陀螺平移不稳（DEV-20261102-06）

- 根因：**本车旋转矩阵约定与上游相反**（跟随增益 +1.5 才稳；麦轮 wz 项四轮全负号），但平移投影仍用标准旋转矩阵 → 小陀螺时 offset 大范围变化，平移反向画圈。跟随模式 offset 小所以不显形。
- 修复：`CHASSIS_OFFSET_PROJ_DIR = -1`（theta 取反）。
- 排除：输出限幅是四轮等比缩放（保比例），饱和只整体变慢不导致方向漂移。
- 通用教训：**本车所有"坐标系旋转"相关符号都要按"约定相反"复核一遍**（已发现的：跟随增益、wz 项、平移投影）。
