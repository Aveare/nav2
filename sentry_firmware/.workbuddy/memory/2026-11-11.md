## 环境坑(会再次遇到)

- `build/CMakeCache.txt` 里的 `CMAKE_HOME_DIRECTORY` 还是旧路径 `C:/RoboMaster/RM-JIT-CR`(工程目录改过名),直接 `ninja -C build` 会报 "source directory ... does not appear to contain CMakeLists.txt"。删除 CMakeCache.txt 重建即可。
- `CMakeLists.txt` 用裸名 `arm-none-eabi-gcc`,cmake 按 PATH 解析:重建缓存时会抓到 `C:\Toolchain\bin`(15.3.1),与历史产物(14.2 Rel1)不是同一套。要复现历史构建,先把 `C:/Program Files (x86)/Arm GNU Toolchain arm-none-eabi/14.2 rel1/bin` 放到 PATH 最前再 cmake。
- 沙箱内子进程(arm-none-eabi-gcc/as)无法往 `build/` 写 .obj,表现是 `can't create ...obj: Permission denied` + `error writing to -: Invalid argument`。不是代码问题,编译必须走提权(sandbox bypass)。
