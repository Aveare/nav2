## yaw 轴开源方案调研 + 深化改造计划

产出:`.Doc/yaw轴深化改造计划.md`(P0~P7 分阶段,含判据/回退/风险矩阵/标定流程)。

### 源码级调研结论(四份实现)

- **rm-controls**(rm_gimbal_controllers)：yaw 世界系闭环 + 最短角；力矩合成含"底盘角速度正弦补偿 `-k(ωz)·ωz`"和 `+joint_vel −imu_rate` 换算项；**没有** yaw 摩擦补偿/输出死区/斜率限制（之前我按 changelog 说有，已更正）。它那些补偿项是"关节速度控制器"架构的代价，我们世界系双闭环不需要 → 否决照抄。
- **南理工 LQR+ESO**：`tau_ff = J·α_ref + B·ω_ref + τc·tanh(ω_ref/ε)`，再叠加三阶线性 ESO（β=3ω0/3ω0²/ω0³）+ 力矩偏置慢积分 + 软/硬/斜率三级限幅，ESO 带速度与加速度门控。**前馈+ESO 全部采纳**，LQR 本体不采纳。
- **复旦 SMC**：`u = J(ddref − C(ω−dref) − ε·sat(s) − K·s)`，数学上等价于"PD + 边界层 + 参考加速度前馈"，与我们现有角度 P + Kd 同源 → 否决替换。
- **川大滑模**：算法否决，但两条工程教训采纳：切换控制律必须输出连续化；必须有积分清理（否则死机后残留卡死）。

### 本车三个关键诊断(计划的主线)

1. **惯量前馈主语错了**：现在用 IMU 世界系 α 差分，而小陀螺稳态下世界系 α≈0、关节 α 才是要加速的量 → 这一项在小陀螺段基本失效。应改用关节 α（电机 speed_aps 差分）。
2. **B=15 不是摩擦系数**：300°/s 时 `B·ω` 折电流域 = 0.54A ≈ 0.40N·m，比真实摩擦（<0.05N·m）大一个数量级 → 它实际在补电压域非线性/反电动势残差。这解释了"欠补偿仍能跑"和"B=18 失稳（等效负阻尼）"。切电流模式后**不能简单乘 0.6554**，必须重标定。
3. **缺库仑项**：摩擦模型只有 `B·ω`，零速附近给不出恒值 τc → 这就是静止残差 ±1.4° 和微动粘滑的物理来源。加 `τc·tanh(ω/ε)`。

### 其它自查

- `YAW_ECD_GREATER_THAN_4096` 是死宏（全工程无引用）→ 待删。
- `DJIMotorStop` 只置标志位、不清 PID 积分（IL=100≈0.6% 满量程，风险低）→ P0-2 修。
- 标定方法设计：关掉全部前馈，用 CHASSIS_ROTATE_SPEED 跑 100/150/200/300/450 五档恒速小陀螺，此时世界系≈0、速度环误差≈0，**稳态输出即维持该关节速度的力矩**，正反两向各测 → 最小二乘得 a(库仑) 与 b(粘性)。

## 深度审核(同日晚,对上述计划)

逐条对照代码与物理模型复核,发现三类问题:

1. **诊断1(惯量前馈主语)疑似物理错误**:yaw 轴与底盘自转同为竖直轴,欧拉方程取惯性系得 `J·α_world = τ_m + τ_f(ω_joint)`。
   惯量前馈主语应是世界系 α(理想为 α_ref),摩擦前馈才是关节量——现有代码结构正确。
   "维持 300°/s"需要的是摩擦力矩(B·ω_joint 已覆盖),不是惯量力矩。底盘加/减速段用 α_joint 前馈 = 注入 −J·α_chassis 反向力矩
   (关节系完整模型应含 +J·α_chassis 补偿,计划漏掉)。已在 MEMORY.md 铁律1 标注"存疑待定稿"。
2. **P2 标定方法两处缺陷**:①恒速扫掠 α≈0,J 不可辨识(回归 α_joint 只会拟出≈0),J 必须在底盘静止的纯瞄准工况加激励辨识

## pitch 轴优化计划(新结构)

产出:`.Doc/pitch轴优化计划.md`。触发:云台结构与材料整体更换 → 质量/质心/惯量/刚度/限位/间隙全变,
旧参数只作起点。

### 开源调研新收获(与 yaw 不同的部分)

- **rm-controls 重力前馈**:`τ = -(mass_origin × gravity).y`,重力向量变换到 pitch 关节子连杆系;
  `mass_origin` 存的是**质量×质心(一阶矩)**,所以不必称质量 → 我们的 `A·cos(θ−φ)+B` 拟合同样只辨一个标量。
- **诺丁汉联队(双惯量)**:`ω_f ≈ √(k_t(1/J_m+1/J_l))`,结构越软频率越低;落入控制带宽后"加增益=给共振喂能量"。
  **新结构刚度未知是最大风险**,必须先辨识(B7 敲击法 + 可选扫频)。
- **RM2026 摩擦轮那篇**:陷波(Q=30)与低通的量化对比,关键提醒"低通要加在输入干扰上,不是加在输出的低频假姿态上"。
  我们的上抬异响是**输出力矩纹波**激励结构,所以输出低通位置是对的;若新结构表现是测量噪声型抖动,要改在反馈通道。
- 伺服行业实践:扫频 → 陷波(中心频率/深度/Q)→ 重调增益;陷波对频率漂移敏感;降增益只是藏问题。

### 本车 pitch 的定量发现

- `MaxOut=4000` 码 ≈ 4.88A ≈ 1.47N·m;若新结构 1.2kg×0.10m → τ_gmax≈1.18N·m,**余量只剩 25%**,
  新结构更重就抬不动 → 必须用 P2 标出的 A 复核 IL 与 MaxOut(旧结构从没算过这笔账)。
- pitch 经 19:1 减速,关节转速低、力矩大 → 摩擦库里项占比高于 yaw,不能照搬 yaw 的 B。
- 计划顺序被重排为:机械基线(限位/IMU 轴向/零位)→ **共振辨识** → 重力标定 → 重力前馈 → 滤波/摩擦 → 增益。

- 共性:功率上限都在**输出层(电流)或指令层(目标速度)**截断,速度环照常跑——我们正缺这一层。
