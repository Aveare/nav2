## Git 远端跟踪引用写不进去（本机环境坑）

- 现象：`git fetch` / `git update-ref refs/remotes/origin/main` 都报成功（exit 0，日志还会打 `[new branch]`），
  但 `.git/refs/remotes/origin/` 目录仍是空的，`git show-ref` 看不到 refs/remotes，
  `git branch --set-upstream-to=origin/main` 报 "requested upstream branch does not exist"，
  `git status` 显示 `[gone]`。加 `dangerouslyDisableSandbox` 也一样，排除沙箱权限。
- 绕过：手工建引用文件即可持久化——
  `mkdir -p .git/refs/remotes/origin && printf '<sha>\n' > .git/refs/remotes/origin/main`。
- 猜测是 git 的 "临时文件 + rename" 写 ref 方式被本机文件系统/安全软件吞掉；不要在这上面反复排查代码。
