## 0. 为什么需要这份文档

三份计划各自都写着「P1 装机基线,第一件事」——但**车只有一辆,第一次上电只有一次**。三份 P1 的依赖是交叉的,
按分计划各做一遍会出现三个问题:

1. **重复上电**:yaw 要静态基线、pitch 要静态保持、底盘要推车验符号,其实是同一次上电能拿完的数据;
2. **顺序踩雷**:yaw-B4 的小陀螺判据会被底盘力臂误差污染(底盘-V3 才是它的前置),但分计划里两者各写各的;
3. **烧录浪费**:每改一个 config 值就要重编重烧,一次 5 分钟起。22 小时的测试时间里,如果按分计划逐项改参数,
   光是烧录和换固件就能吃掉 2 小时。

所以本文的产物是一张**统一时间轴** + 一张**固件批次表**。分计划的编号全部保留,本文只负责排序和合并。

### 1.1 一条必须记住的前提

**yaw 能出力,依赖 RoboMaster Assistant 里的「电流环」开关处于开启状态。**
2026-11-11 定案:该开关关闭时,0x2FE 电流帧被电调静默忽略——**反馈报文(角度/转速/温度)一切正常,只是不出力**,

## 3. S0 断电机械检查(不烧录,≈40 分钟,建议两人)

**这一步不需要改代码、不需要新固件,车装好当天就能做。做完产出三个数,是 S1 的前提。**

### 3.1 pitch 限位实测(H1)

原 `pitch-B2` 写的是「断电手推」——**实际做法建议改为「上电但不解锁」**:IMU 在跑才能直接读 `Pitch` 角,
断电时读不出数。安全前提:遥控器已拔或处于锁定位,确认没人能碰到解锁开关。

| 步骤 | 操作 | 记录 |
|---|---|---|
| 1 | 上电,不解锁(电机不使力),开 Ozone | — |
| 2 | 手推 pitch 到**上**机械极限(感到/看到撞到底但不用力压) | `Pitch` 角、`pitch_motor->measure.ecd` |
| 3 | 手推 pitch 到**下**机械极限 | 同上 |
| 4 | 写回 config:`PITCH_MAX_ANGLE` = 上限 − 2°,`PITCH_MIN_ANGLE` = 下限 + 2° | — |

**为什么要留 2°**:限位判据是「目标角钳位」,不是「撞上去停住」。留 2° 保证任何控制超调都还在安全行程内。
若上下限之差 < 20°,先别写 config——行程过小说明装配/传动有问题(减速比、连杆角度),回查机械。

### 3.2 零位三读数(H2)

| 读什么 | 怎么读 | 写回哪个宏 |
|---|---|---|
| pitch 水平位 | 用水平仪/目测摆平,读 `Pitch` 应≈0,同时记 `pitch_motor->measure.ecd` | `PITCH_HORIZON_ECD` |
| yaw 正对底盘纵轴 | 云台几何中线与底盘纵轴对齐,读 `yaw_motor->measure.ecd` | `YAW_CHASSIS_ALIGN_ECD` |
| pitch 上下限 | 见 3.1 | `PITCH_MAX/MIN_ANGLE` |

**读数方式**:Ozone live watch 直接看 `gimba_IMU_data->Pitch`(deg)、`pitch_motor->measure.ecd`、
`yaw_motor->measure.ecd`,**不需要改代码加日志**。

> 零位是「物理对中」不是「软件归零」。摆位时以机械结构(限位、连杆中线、底盘纵轴)为准,不要以「让 IMU 显示 0」为准
> ——后者会把 IMU 安装偏差固化进零位。

### 3.3 结构与传动确认

| 项 | 判据 |
|---|---|
| pitch 物理减速比仍为 19 | 手转 pitch 关节 30°,看 `speed_aps` 累积角度 / 关节实转角 ≈ 19。**config 无此宏**(只有 `REDUCTION_RATIO_WHEEL/LOADER`),pitch-P4-0 的 `/19` 换算是硬编码,依赖这条核验;不是 19 则全部换算要改,**且 pitch 计划整份作废重写** |
| pitch 自由摆动(pitch-B4) | 断电或不解锁手抬松手:无卡滞、无异常撞击声;目测回差(让角度来回小幅摆,记「同位置来回的读数差」) |
| yaw 传动 | 手转云台一周,无卡顿/无刮擦;线缆不被拉紧 |
| 走线 | 新结构线缆长度变了——全程推满上下限,**线缆任何位置都不能绷直**,否则它就是一个随角度变化的弹簧,会污染 pitch-P2 的重力拟合 |

## 4. S1 首次上电与安全确认(≈1 小时)

**烧 F1 批次**(= F0 + S0 的三个数写回 config)。烧完这一版,**S2 全程不再换固件**。

### 4.1 上电顺序(严格照做)

1. **只上控制板,先不接电机电源** → 看 RTT/Ozone:三轴角度、`Gyro[]` 是否都有数、有没有刷屏报错;
2. 接电机电源,**不解锁** → 手推三轴,看角度读数是否跟手、符号是否合理;
3. **pitch-B1 IMU 轴向核验(H3)**:手转 pitch 单轴,记录 `Gyro[0]/[1]/[2]` 三个通道哪个响应最大;
   - 判据:响应最大的通道与 `pitch_config.other_speed_feedback_ptr` 指向的通道一致,且**符号与 `Pitch` 增量同向**;
   - 不一致 → 改指针与方向,**改完重烧再验**。这一步没过,永远不解锁 pitch;
4. **首次解锁**:手虚扶云台,只观察 3 秒不推杆。看是否:
   - 云台单向持续转(不收敛)→ **立刻锁车**,IMU 轴向/符号错,回 3;
   - pitch 有闷响/顶住感 → 限位没写对,回 S0-3.1;
   - yaw 完全不出力(手能轻易转动,且无阻力)→ **先查 Assistant 的「电流环」开关**(见 §1.1);
   - 三轴都静住、有小幅高频抖动但不发散 → **正常**,抖动幅值记下来当 B1 基线。

### 4.2 S1 结束判据

- [ ] 三轴 IMU 轴向与符号全部核验通过
- [ ] 首次解锁不发散、不撞限位、yaw 有出力

- [ ] pitch 物理减速比已确认 ≈19(config 无此宏,P4-0 的 /19 换算依赖这条核验)

### 5.1 第 5 步为什么是合并测,以及三方交叉怎么读

小陀螺恒速时,云台瞄准保持在世界系,`ω_joint = −ω_chassis`——**大小相等、方向相反**(云台不动,底盘在它"底下"转)。
于是同一个物理量有三个独立来源(**下文所有比对都指大小,先取绝对值再比,不要拿带符号的原始值直接比**):

| 来源 | 量 | 性质 |
|---|---|---|
| 外部计时(转 10 圈) | 底盘真实转速 | **唯一真值**,与代码的几何完全无关 |
| `est_wz`(四轮逆解) | 底盘转速 | 依赖 `WHEEL_BASE/TRACK_WIDTH/力臂 340mm` |
| `yaw_motor->measure.speed_aps` | yaw 关节转速 | 依赖 yaw 编码器与减速比 |

**三个数一致 → 力臂修正、轮径、yaw 反馈整条链同时验完**;不一致时按下面定位,不要一起调:

| 现象 | 结论 |
|---|---|
| 计时法 ≠ `est_wz`,但 ≈ `speed_aps` | **几何错**(力臂/轴距/轮距/轮径)。查 `WHEEL_BASE=500 / TRACK_WIDTH=460 / RADIUS_WHEEL=75`,**不要**去调 `CHASSIS_ROTATE_SPEED` |
| 计时法 ≈ `est_wz`,但 ≤ `speed_aps` 差很多 | yaw 编码器/减速比/零位问题,查 yaw 侧 |
| 三者都 ≈ 但与指令 `CHASSIS_ROTATE_SPEED` 差得多 | 指令到轮速的换算错,或触了 6000RPM 限幅(看第 6 步) |

> **注意 H4**:如果 `est_wz` 与计时法偏差 >10%,**yaw-B4 的数据要标注「底盘基准存疑」**,不能直接当作 yaw 的
> 关节速度判据使用。yaw-B4 的「关节速度与指令偏差<10%」这条,前提是「指令」本身对应真实转速。

## 6. S3 标定(≈4 小时,**烧 F2 批次:前馈全关**)

F2 的 config 改动(改完只烧一次,三段标定共用):

```
YAW_INERTIA_FF_GAIN  = 0        YAW_FRICTION_FF_B = 0
YAW_REF_FF_GAIN      = 0        (库仑项尚未存在,无需关)
PITCH_GRAVITY_FF_GAIN 保持 0    (本来就是 0)
```

> **标定期间会看到「平时看不到的坏现象」**:450 档稳态 offset 会到 1.5° 甚至更大,
> 因为 IL=100 码(≈0.013N·m)根本扛不动摩擦,力矩是靠「角度环 P × 速度环 P」通路建立的。
> 这是正常现象(见 yaw-P2),**不要当故障回退**。判据是数据自洽,不是手感。

> **标定前先解决两个执行缺口(否则 S3 会比计划多烧 5 次录)**:
> 1. **五档转速没有运行时入口**。`chassis.c:293` 是 `chassis_cmd_recv.wz = CHASSIS_ROTATE_SPEED;`
>    ——**写死的宏**,100/150/200/300/450 五档意味着改 5 次 config 重烧 5 次。
>    两个解法:(A) 加一个 `YAW_FRIC_CALIB_SWEEP` 临时标定模式,每档 2~3s 自动阶梯递增、正反交替,
>    同时 `[yawcal]` 打点(推荐,一次烧录拿全数据,与当年 `YAW_ESC_SELFTEST_ENABLE` 同一套路);
>    (B) 接受 5 次重烧(约 25 分钟),但每档都要重新对零位,数据一致性差。
> 2. **S3-c 的"每 5° 一档"不要当作硬要求**。遥控器推杆积分的精度做不到精确 5°,
>    而 `I = A·cos(θ−φ)+B` 的最小二乘**对 θ 是否等间隔没有要求**。
>    正确做法:在行程内取 **8~9 个散点**、跨度尽量铺满,每点记录**实际读到的 `Pitch` 值**而不是名义档位。

### S3-a yaw 摩擦(≈1 小时)

小陀螺 100/150/200/300/450 五档,每档稳定 3s,**正反交替各一遍**(摩擦不对称 + 控制线缆扭转累积)。
读 `out` 与 `speed_aps` → 拟合 `I = a + b·ω`。
- `a` = 库仑项 `YAW_FRICTION_COULOMB`(码),`b` = 粘性项 `YAW_FRICTION_B`(码/(deg/s))
- 预期 `a ≈ 370~1100` 码、`b ≈ 0.6~3.9` 码/(deg/s)。**落在区间外先怀疑量纲/域错,不是摩擦异常**
- 判据 R² > 0.95;正反 `a` 差值 <20% 判对称,差值大则记录不对称量

### S3-b yaw 惯量 J(≈40 分钟,可延后)

**底盘静止**(与 S3-a 的工况相反,必须单独做):角度目标给 ±30° 阶跃或 0.5~2Hz 正弦,各 10 次,
用 `out − (a + b·ω)` 对 α(IMU 世界系差分)回归得 J。
- 判据 R² > 0.9(**放宽到 0.9**)。低于 0.9 或 J ≤ 0 或与现值差 3 倍以上 → **判定辨识失败,yaw-P5 直接跳过**,
  不要用调 GAIN 掩盖 b0 错误
- **这一项只服务于 yaw-P5(ESO)。若 P5 本来就延后,J 可以不做,S3 省 40 分钟**

### S3-c pitch 重力(≈1 小时,核心)

底盘静止,`PITCH_GRAVITY_FF_GAIN=0`,从下限到上限**每 5° 一档**(8~9 档),每档到位静态 3s,重复 3 次。
读 `Pitch` 与速度环稳态 `Output` → 拟合 `I(θ) = A·cos(θ−φ) + B`。
- `A` → `PITCH_GRAVITY_A`;`φ` → `PITCH_GRAVITY_PHASE`;`B` → `PITCH_GRAVITY_OFFSET`
- 判据:R² > 0.95;φ 在 ±10° 内;A 三次重复波动 <10%
- **交叉校验**:`τ_gmax = A/16384 × 20A × 0.3N·m` 应在新结构「质量 × 质心距 × 9.8」的 ±30% 内

> **顺手复核一件旧账**:`MaxOut=4000` 码 ≈ 4.88A ≈ 1.47N·m。如果新结构 1.2kg × 0.10m,τ_gmax ≈ 1.18N·m,
> **余量只剩 25%**。A 标出来后若发现 `MaxOut` 不够覆盖 A,先改 `MaxOut` 与 `IL` 再继续,别让前馈去补饱和。

### S3-d 底盘功率数据采集(≈40 分钟,**可延后但建议顺带做**)

- 3 档匀速直线(各 10s)+ 3 档急加速(起步到满速 3 次);
- 记录 `speed_aps ×4`、`out ×4`、`[chcal]` 的 `be` 列(缓冲能量);
- 用途:拟合 `P = Σ(τω) + K1Σ(τ²) + K2Σ(ω²) + K3`(底盘-P3)

> **先看一个数再决定要不要做功率控制**:如果 S2/S3 全程 `buffer_energy` 都没掉到 40J 以下,
> 说明当前底盘功率远没触限(4×3508 + 云台,实测小陀螺整车仅约 22W)。此时功率控制是「防御性功能」,

## 7. S4 补偿落地(≈4 小时,分批烧录)

**从这里开始逐项改参数,每项各自验收。单变量纪律见 §9。**

### 7.1 F3:yaw 库仑项 + pitch 重力前馈(≈1.5 小时)

两处改动在**不同轴**上,可合并为一版固件(见 §9),但**验收必须分开看,不能一起判断**。

新增宏(目前代码里还没有,需先加):

```c
#define YAW_FRICTION_COULOMB   /* S3-a 的 a,电调码 */      #define YAW_FRICTION_EPS  30.0f   /* deg/s */
#define YAW_INERTIA_J          /* S3-b 的 J,码/(deg/s²);S3-b 跳过/失败时本宏不新增,见下方 J 与 MVP 的关系 */
#define PITCH_FRICTION_B / PITCH_FRICTION_COULOMB / PITCH_FRICTION_EPS   /* P4-0 才填,先占位 0 */
```

落脚公式(**量纲纪律,这是最容易错两遍的地方**):

```c
// yaw:三个标定值都是「电调码」域,已吸收 16384/25000
tau_ff = YAW_INERTIA_J * alpha + YAW_FRICTION_B * omega_joint
       + YAW_FRICTION_COULOMB * tanh(omega_joint / YAW_FRICTION_EPS);
// ⚠ 禁止再乘 YAW_CURRENT_DOMAIN_SCALE,旧实现的 GAIN*SCALE / B*SCALE 必须随之删掉
//   否则等于乘两次 0.6554,等效增益少 34%,现场只表现为「有点软」,极难定位
```

> **J 与 MVP 的关系(勿卡在这)**:`YAW_INERTIA_J` 只在 S3-b 成功后引入;S3-b 跳过/失败时,
> **惯量项维持现有实现不动**(`YAW_INERTIA_FF_GAIN * α * SCALE ≈ 1.229` 码/(deg/s²),理论×0.625 的旧账),
> F3 只把摩擦两项换成标定值并新增库仑项——不要为凑 MVP 编一个 J 出来。

| 验收 | 判据 | 回退 |
|---|---|---|
| yaw 静止残差 | 跟随 offset 稳态 ±1.4° → **<0.8°** | `COULOMB=0` 即刻回现状 |
| yaw 微动粘滑 | 30° 小步无「先顿一下」 | `EPS` 30→50 |
| yaw 零速抖振 | 静止 out 峰峰值不增超 20% | 同上 |
| pitch 各角稳态电流 | 平均下降 ≥50% | `GAIN=0`(模型参数保留) |
| pitch 回水平残留 | <0.5°,不再靠 DeadBand 兜底 | — |
| **pitch 符号首检** | **施加后稳态电流必须下降;不降反升立刻 GAIN=0** | 符号反 = 助推下坠,是本计划唯一可能伤机械的失误 |

pitch 的 θ 取 **IMU 欧拉 `Pitch`**(不是编码器角):重力是世界系方向的量,编码器角在 IMU 侧装/翻转或零位偏移时
与「重力方向」不等价,用编码器算 cos 会直接错相位。

### 7.2 F4:pitch 摩擦 + 滤波重定(≈2 小时,**视 B7 结果决定做不做**)

**先做 P4-0 标定**(P2 静态保持是 ω≈0,测不出粘性项):
重力前馈已通过后,恒定杆量给关节 3/5/10/20 deg/s 四档,上下双向各一次,稳态 `out` **减去重力前馈**后
对 `ω_joint`(= 转子速度/19)回归 → 截距=库仑、斜率=粘性。判据 R²>0.90(低速非线性强,不要求 0.95)。

**再按 B7 选路线**,不要先改参数:

| B7 结果 | 路线 |
|---|---|
| f_res > 40Hz 或无明显峰 | 维持输出低通,只重扫 RC:0.006 / 0.010 / 0.014 三档 |
| 10Hz < f_res < 40Hz(落入带宽) | 先降速度环 Kp;仍响再上二阶陷波(**属新增滤波器,需批准**) |
| f_res < 10Hz | 软件救不了,先反馈机械(加筋/换材料/缩短悬臂) |

### 7.3 F5:底盘功率限幅(≈1.5 小时,条件触发)

**前提**:S3-d 数据显示 `buffer_energy` 曾逼近 0,或已加装发射/超级电容。
实现走 **L1(指令层缩轮速)**,只改 `chassis.c`,不动模块层;判据:
- 连续大功率机动 60s,`buffer_energy` 不归零
- 缩放下直行 3m 偏移 <10cm(L1 的主要风险:四轮协调性)
- 平均 `P/P_limit` > 0.85(不保守浪费)
- `P_limit` 收到 0x0201 时刷新;数据异常 **fallback 80W**

L1 实测走直线不达标,才考虑 L2(模块层缩电流,需按分组白名单,属模块级改动)。

## 9. 单变量纪律:一条修正

三份计划都写「一次只改一个参数」。这条纪律**要按轴分开理解,否则会多烧四轮**:

- **同轴串行**:同一根轴上一次只改一项。yaw 的 COULOMB 和 J 不能同一版上,**否则 offset 改善无法归因**;
- **跨轴并行**:yaw 与 pitch 是物理独立的两套控制器、两个电机、两个负载,改 yaw 不影响 pitch 的对照性
  → **F3 同时改两轴是允许的,但验收必须分开**(先验 yaw 残差,再验 pitch 电流,不要混在一次跑车里看);
- **底盘独占一轮**:底盘参数(力臂、斜坡、限幅、功率缩放)会通过关节耦合影响 yaw 的世界系反馈通道
  → **改底盘的那个固件里,不要同时改云台参数**。

## 10. 止损清单(看到立刻断电/锁车)

| 现象 | 最可能原因 | 处置 |
|---|---|---|
| 解锁后云台单向疯转不收敛 | IMU 轴向/符号错(H3) | 立即锁车,回 S1-4.1 第 3 步 |
| pitch 顶住有闷响、电机发烫 | 限位没写对(H1) | 锁车,回 S0-3.1 重测 |
| yaw 反馈全正常但完全不出力 | **Assistant「电流环」开关被重置** | 先查这个,再查任何别的原因 |
| 底盘指令转速明显不符 | 力臂/轮径/力臂修正未验证 | 查 `WHEEL_BASE/TRACK_WIDTH/RADIUS_WHEEL`,**不要**调 `CHASSIS_ROTATE_SPEED` |
| 电机几分钟内 >60℃ | 摩擦补偿过量 / 增益过高 / 前馈符号错 | 关前馈,回 S3 复核标定 |
| 出现新的高频啸叫 | 补偿项激励了新共振 | 立即回退上一版参数,补做 B7 |
| 静止 out 峰峰值突增 >50% | 库仑项 EPS 太小(零速抖振) | `EPS` 30→50,或 `COULOMB` 减半 |
| RTT 被 `CAN Send FIFO full` 刷屏 | 台架 CAN 无带电节点(无 ACK) | 上车供电齐全不会出现,忽略;若上车仍刷屏则是真故障 |
