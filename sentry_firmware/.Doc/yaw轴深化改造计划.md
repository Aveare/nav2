## 0. 一句话结论

本车 yaw 的问题**不是控制器不够先进**:摩擦前馈 B 是电压域经验补偿的遗留值、摩擦模型缺库仑项、且无扰动观测。
主线是"把摩擦模型标定正确 + 补两项",**不换控制器结构**(滑模/LQR 全部否决,理由见 §2.6)。
惯量前馈的"主语"(世界系 α)经深审确认**本来就正确**(§3.1),不做换源;可选改进是用参考加速度 α_ref
替代含噪实测 α(P4)。

## 2. 开源实现深度对比(源码级)

### 2.1 rm-controls / rm_gimbal_controllers(ROS,标杆框架)

读 `gimbal_base.cpp` 的实际做法:

- **世界系闭环**:`odom2gimbal_` 四元数 → RPY,误差用 `angles::shortest_angular_distance` 折 ±π;
- **yaw 力矩合成**:`pid_pos + (-k_comp(ω_z)·ω_z) + k_v·vel_des + joint_vel − imu_rate`;
  其中 `-k_comp(ω_z)·ω_z` 是**底盘角速度的正弦经验补偿**(`chassis_comp_a~d` 四个参数);
- **没有** yaw 摩擦补偿、**没有**输出死区、**没有**力矩斜率限制(pitch 才有重力前馈);
- 惯量前馈只在 `EXTERNAL_MPC_AIM` 分支有(`moment_of_inertia × yaw_acc`)。

**判定**:它为"关节速度控制器 + 关节反馈"这个架构付出了额外换算代价(那四项)。
我们的架构是 IMU 世界系直接双闭环,这层换算天然不存在。**照抄 = 重复补偿 + 引入相位滞后。否决。**

### 2.2 南理工江阴 Combat:LQR + ESO(github.com/LamdaDay/YAW_Auto_Controller)

源码 `yaw_auto_lqr_eso_controller.c` 的力矩合成(逐项):

```c
tau_ff   = J*alpha_ref + B*omega_ref + tau_coulomb*tanh(omega_ref/eps);  // 惯量+粘性+库仑(平滑)
tau_i    = -k_i * ∫e_theta;
tau_lqr  = tau_ff - k_theta*e_theta - k_omega*e_omega + tau_i;
tau_eso  = -eso_comp_gain * z3 / b0;      // z3=ESO 估计的总扰动,限幅 eso_comp_limit
tau_bias += tau_bias_ki*(tau_cmd - tau_meas)*dt;   // 命令力矩 vs 实测力矩的慢积分
输出:软限幅 → 硬限幅 → 斜率限制(slew_rate * dt)
```

ESO 细节(三阶线性,带宽参数化,可直接移植):

```c
b0 = 1/J;  w0 = eso_bandwidth;  beta1 = 3*w0;  beta2 = 3*w0*w0;  beta3 = w0^3;
e  = theta_meas - z1;
z1 += dt*(z2 + beta1*e);
z2 += dt*(-(B/J)*z2 + b0*u + z3 + beta2*e);
z3 += dt*(beta3*e);
```

工程细节(值得抄):
- **ESO 门控**:只在 `|ω| < eso_omega_gate` 且 `|α_ref| < eso_alpha_gate` 时启用补偿,避免与主控抢输出;
- **dt 护栏**:`0.1ms < dt < 50ms`,越界回落 1ms;
- **库仑项用 tanh 而非 sign**:消除零速抖振;
- 明确写出"GM6020 需先做电流-力矩标定"——正好对应我们已切电流模式。

**判定:三项前馈 + ESO 全部采纳(分阶段);LQR 本体不采纳**(需要完整模型辨识 + 改控制结构,收益低于"我们已有级联 PID + 前馈")。

### 2.3 复旦星云EGA:滑模(github.com/SadMei/SMC_Controller)

源码只有 10 行,`slidingmodec.cpp` 全文逻辑:

```c
error = angle - ref;
dref  = ref - ref_last;            // 参考角速度(每拍差分)
ddref = dref - dref_last;          // 参考角加速度
if (|error| < error_eps) { u = 0; return; }         // 误差死区
s = C*error + (ang_vel - dref);                     // 滑模面
u = J*(ddref - C*(ang_vel - dref) - epsilon*Sat(s) - K*s);
限幅 ±u_max;
```

**数学上等价于**:`u = J·K·[ (C·e + ė) 的 PD 型组合 ] + J·ddref`,即**"PD + 边界层饱和 + 参考加速度前馈"**,
只是增益打包成 `J·K`。它没有积分项,稳态精度靠边界层外的 K·s。

**判定:与本车现有"角度 P + Kd(on measurement) + 内层速度 PI"结构同源,不换。** 可借鉴的只有两点:
①误差死区置零(我们已有 0.5°);②`Sat` 边界层替代 D 项硬限幅(我们 D 限幅 8,效果类似)。**否决替换。**

### 2.4 川大火锅:多滑模面(github.com/GreenHand314/Sliding)

其开源说明里两条工程教训比算法本身值钱:

1. **切换控制律时必须输出连续化**,否则 pitch 输出跳变;
2. **必须有积分清理接口**,否则电机死过之后积分残留导致卡死/超射速。

**判定:算法否决(同 2.3),两条工程约束采纳** → 对应 P0-2(停机清积分)与既有"增益切换连续"纪律。

## 3. 本车问题的物理归因(本计划的核心)

### 3.1 【深审定案】惯量前馈的主语是世界系 α,不换源(2026-11-12 修订)

当前代码:

```c
float a = (gyro_deg - yaw_gyro_last) / dt;   // Gyro[2]:IMU 世界系 yaw 角速度
yaw_alpha_f += LP*(a - yaw_alpha_f);
yaw_inertia_ff = GAIN * yaw_alpha_f * SCALE + B * motor.speed_aps * SCALE;
```

初版曾主张"换源到关节 α",深度审核推翻。定案依据:yaw 轴与底盘自转轴同为竖直轴,
欧拉方程在惯性系(世界系)下就是 `J·α_world = τ_m − τ_f(ω_joint)`:

- **惯量项的主语 = 世界系 α**(理想取参考轨迹的 α_ref),**摩擦项的主语 = 关节量 ω_joint**。
  现有代码(惯量用 IMU α、摩擦用 speed_aps)结构本来就正确;
- 小陀螺稳态"关节在 300°/s 上维持"需要的是**摩擦力矩**(B·ω_joint 已覆盖),维持恒速不需要惯量力矩,
  此时惯量前馈输出 0 恰是正确行为,不存在"这一项失效";
- 若改在关节系建模,完整方程是 `J·α_joint = τ_m − τ_f(ω_joint) − J·α_chassis`——**必须补 +J·α_chassis
  底盘加速项**(rm-controls 那组正弦补偿就是它的速度版)。只换 α 源而不补这项,等于在底盘加/减速段
  注入 −J·α_chassis 的反向力矩,且恰在该项最大处弄错方向。rm-controls 为关节架构付出的换算代价,
  正是世界系架构天然免掉的;
- 两种记法只在底盘静止的纯瞄准工况相等(换源在该工况无副作用,但也无收益)。

真正值得做的改进:实测 α 来自 IMU 陀螺 200Hz 差分+低通,噪声大且滞后于参考 →
**用参考轨迹差分的 α_ref 替代实测 α**(模型逆前馈本就该用参考量,见 P4)。
**J 的辨识必须在底盘静止的纯瞄准工况加激励完成**(该工况 α_joint=α_world,见 P2 方法 B)。

### 3.2 B=15 不是"摩擦系数",是电压域的经验补偿增益

量纲验算:joint 300°/s 时,`B·ω = 15×300 = 4500`(电压码),折电流域 2950 码 = **0.54A ≈ 0.40 N·m**。
而 GM6020 yaw 轴(带滑线/线缆)的真实摩擦量级估算为 库仑 0.05~0.15 N·m + 粘性 0.005~0.03 N·m·s/rad
(300°/s = 5.24 rad/s 时粘性贡献 0.03~0.16 N·m),**合计 0.08~0.31 N·m**。
也就是说 0.40 N·m 是估算上限的约 1.3~5 倍
→ **它补偿的主要不是摩擦**,而是"电压码 → 力矩"的非线性等效(含反电动势残差)。
(初版"合计不足 0.05 N·m / 大近一个数量级"与所列量级自相矛盾,已修正。)

这就解释了两件历史事实:
1. 为什么"欠补偿 60%"却仍然能跑——物理摩擦本来就小,B 大头的用途是别的;
2. 为什么 B=18 会失稳——当它大于某个临界值,等效为**负阻尼**,与摩擦无关。

**结论:切电流模式后不能把 B 简单乘 0.6554 了事(现在正是这么做的)。必须重新标定,
标定出来的粘性项应显著小于 9.83,库仑项才是真正的物理摩擦。**
按上面量级换算(7380 码/N·m),预期标定结果落在 **τc ≈ 370~1100 码、B ≈ 0.6~3.9 码/(deg/s)**;
若实测落在区间外,优先怀疑量纲/域错误,而不是摩擦真的异常。

> **证据强度说明**:0.40 vs 估算上限 0.31 只差 1.3 倍,量级对比本身**不足以定论**,
> 只能支持"B 主要用途可能不是摩擦"这一倾向。最终定性以 P2 标定数据为准,
> 在 P2 完成前不得把本条写进《本车调参结论》当作既成结论。

### 3.3 缺库仑项 → 静止残差与微动粘滑

摩擦模型 `τ = τc·sign(ω) + B·ω` 中,我们只有后半项。零速附近 `B·ω→0`,但真实摩擦是**恒值 τc**,
于是:
- 静止/微动时没有摩擦力前馈,只能靠积分慢慢建立 → **±1.4° 残差的物理来源**;
- 微动起步时要先"顶过"静摩擦 → 粘滑感;
- 用 `sign()` 会在零速抖,+ `tanh(ω/ε)` 平滑是标准做法;
- 佐证(2026-11-12 深审补):前馈全关时,摩擦力矩只能经"角度环 P × 速度环 P"通路建立
  (IL=100 码 ≈ 0.013 N·m 扛不动),按 480 码/°(Kp 24×20)折算,300°/s 档摩擦 ≈740 码(0.1N·m)
  对应稳态 offset ≈ **1.5°——与"±1.4° 残差"实测吻合**,反证摩擦静差归因。

### 3.4 无扰动观测 → 线缆、滑环、磁滞无解

yaw 每圈都有线缆扭力(累积型扰动)、滑环摩擦不均、电机齿槽力矩。这三类都不是 `a+b·ω` 能描述的,
手写系数越写越多。ESO 把它们统一估成 z3,是唯一低成本的覆盖手段。

### 3.5 力矩上限与最高转速的耦合

±3A ≈ 2.22 N·m 是电流帧物理上限。小陀螺 300°/s + 加速度时,扭矩需求 = 摩擦 + J·α + 线缆,
若逼近 3A 就会"推不动"→ 表现为**自转跟不上指令**。这属于物理上限,不是参数问题(P6 负责摸清边界)。

### 3.6 停机不清积分

`DJIMotorStop` 只置 `stop_flag`,PID 的 `Iout` 保留。我们 IL=100(满量程 0.6%),风险低但非零:
零力→再使能瞬间会带一点残余力矩。**低成本修复(P0-2)。**

### P2 摩擦/惯量参数标定(不需要新固件,≈40 分钟)

**方法 A:摩擦参数(恒速小陀螺扫掠;关键:先关掉所有前馈)**

1. `YAW_INERTIA_FF_GAIN=0`、`YAW_FRICTION_FF_B=0`、`YAW_REF_FF_GAIN=0`、库仑项=0;
2. `CHASSIS_ROTATE_SPEED` 依次设 **100 / 150 / 200 / 300 / 450**(小陀螺恒速),每档稳定 3s。
   原理:准稳态下云台世界系合力矩≈0,**稳态 out 必然等于维持该关节速度的摩擦力矩**(物理约束,
   与速度环误差是否为零无关)。注意 IL=100 码(≈0.013 N·m)扛不动摩擦,力矩实际经
   "角度环 P × 速度环 P"通路建立,表现为稳态 offset ≈ 1.5°(300°/s 档)——**正常现象,勿当故障回退**;
3. 每档读 `out`(码)与 `speed_aps`(deg/s),**正反交替**各测一遍(摩擦不对称,顺带解释"向右微漂";
   交替进行也控制线缆累积扭转);
4. 最小二乘拟合 `I = a + b·ω`:
   - **a = 库仑项 τc(码)**,**b = 粘性项(码/(deg/s))**;预期 τc≈370~1100 码、b≈0.6~3.9 码/(deg/s)(§3.2 换算);
   - 双向差 `(a+ − a−)/2` 即机械不对称量,可选写进 `YAW_FRICTION_ASYM`。

**方法 B:惯量 J(底盘静止的纯瞄准工况,单独做)**

恒速扫掠时 α≈0,回归无激励,J 不可辨识(初版"同帧 α_joint 拟合"方法作废)。改为:
1. 底盘静止,前馈仍全关;角度目标给 ±30° 阶跃(或 0.5~2Hz 正弦),各 10 次;
2. 记录 `out` 与 α(IMU 世界系差分),用 `out − (a + b·ω)` 对 α 做最小二乘,得 J(码/(deg/s²));
   该工况 α_joint=α_world,辨识值就是物理 J,对两种前馈记法通用。

**判据**:拟合残差 R² > 0.95;两向 a 的差值 < 20% 判对称;J 拟合需 α 有足够激励(|α| 峰值 > 200 deg/s²)。
**产出**:`YAW_FRICTION_COULOMB`、`YAW_FRICTION_B`、`YAW_INERTIA_J`(码/(deg/s²))三个物理值。

> **J 不可信时直接放弃 P5(而不是硬调)**:b0 = Kt/J,P5 的全部尺度都建在这个 J 上。
> 若方法 B 的拟合 R² < 0.9、或 J 出现 ≤0 / 与惯量前馈现值差 3 倍以上,判定辨识失败 →
> **P5 直接跳过**,不要用"调 GAIN 凑效果"掩盖 b0 错误(z3/b0 的换算会系统性偏,GAIN 只能掩盖量级)。
> 判据里的"R²>0.95"对 a/b 是硬判据,对 J 可放宽到 0.9,但**低于 0.9 即放弃 P5**。

### P3 库仑摩擦项落地(≈40 分钟)

```c
tau_ff = J * alpha + B * omega_joint + COULOMB * tanh(omega_joint / EPS);
```

(惯量项 α 用世界系——P4 改造后为 α_ref;摩擦两项用关节量 ω_joint。变量名已按 §3.1 定案更正。)

> **量纲纪律(实现时最容易错两遍的地方)**:`YAW_INERTIA_J`、`YAW_FRICTION_B`、`YAW_FRICTION_COULOMB`
> 三个标定值**都是"电调码"域**,已经吸收了 16384/25000 的域换算。因此写进代码时**不得再乘
> `YAW_CURRENT_DOMAIN_SCALE`**;旧实现里 `GAIN*SCALE`、`B*SCALE` 的乘法要随之删掉,
> 否则等于把 0.6554 乘两次(等效增益少 34%)。
> α 一侧:标定与实现统一用 **deg/s²**;若 P4 的 α_ref 由 rad/s² 来源得到,这里必须 ×57.3。

| 判据 | 目标 |
|---|---|
| 静止残差 | 跟随 offset 稳态从 ±1.4° 降到 **< 0.8°**(可直接缩小软死区) |
| 微动粘滑 | B2 的 30° 小步无爬行感、无"先顿一下" |
| 零速抖振 | 静止 out 峰峰值不增加超过 20% |

**回退**:`COULOMB=0` 即回到现状;`EPS` 抖动则从 30 加大到 50 deg/s。

### P4 惯量前馈改用参考加速度 α_ref(`YAW_INERTIA_FF_SRC=1`,≈30 分钟,可选)

初版"换源到关节 α"已否决(§3.1):惯量项主语是世界系,底盘加/减速段 α_joint 前馈会注入 −J·α_chassis
反向力矩。本阶段只做**信号质量改进**:实测 α(IMU 差分+低通)噪声大且滞后,改用参考轨迹差分的 α_ref
(模型逆前馈本就该用参考量;云台保持瞄准时 α_ref=0,与实测行为一致)。

> **实现注意(信号来源,2026-11-12 深审二校)**:不要对原始目标角做二次差分——目标来自 DBUS 帧(14ms 阶梯),
> 二次差分是脉冲串,前馈会逐帧踢。但注意 yaw 前馈块与 pitch 块不同:**没有低通**,
> `yaw_speed_feedforward` 本身就是 14ms 间隔的脉冲串(仅在 ref 变化的那一拍非零)——
> **对它直接差分同样得到正负交替尖峰,与二次差分原始目标同病**。正确顺序:
> 先仿 pitch 块(`PITCH_REF_FF_LP` 结构)对 Δref/dt 做一阶低通得到**连续的 v_ref 副本**,
> 再对 v_ref 差分得 α_ref;跳变帧(ref 重锚定/回中)沿用 `YAW_REF_FF_MAX_DELTA` 判据把副本清零。
> 不得改动已整定的 `yaw_speed_feedforward` 输出路径本身(DEV-93 已定稿,P0-3 判据要求逐位一致)。
> 单位:`yaw_speed_feedforward` 存的是 rad/s(已乘 DEGREE_2_RAD),差分得 rad/s²,
> 与 J(码/(deg/s²)) 相乘前须 ×57.3 折 deg/s²。

| 判据 | 目标 |
|---|---|
| B2/B3 误差峰值 | 比 **P3 后复测值** 下降 ≥20%(不用 P1-B4 当基线,P3 已改变启动段误差) |
| out 抖动峰峰值 | 相比实测 α 源明显下降(前馈信号更干净) |
| 小陀螺稳态 | 不劣化(α_ref≈0,前馈归零,与现状一致) |

**回退**:宏回 0(实测 α)。

### P5 ESO 扰动补偿(≈1.5 小时,含调带宽)

```c
// 200Hz, dt=5ms,b0 = Kt/J(码 → deg/s²)
e = theta - z1;  z1 += dt*(z2 + beta1*e);
z2 += dt*(-(B/J)*z2 + b0*u + z3 + beta2*e);
z3 += dt*(beta3*e);
tau_eso = -GAIN * z3 / b0;   // 限幅 ≤ 3% 满量程起步
```

> **量纲陷阱(实现前必读)**:`YawTotalAngle` 单位是 deg,PID 内部是 rad,b0 里的 Kt 必须用"码域力矩常数"
> (Kt·3/16384,再折 J 的角加速度单位)。三处单位必须统一,否则静默出错。

| 参数 | 起点 | 调整方向 |
|---|---|---|
| `ESO_OMEGA0` | 30 rad/s(≈4.8Hz) | 抖→降;迟钝→升,上限 60 rad/s(200Hz 采样约束) |
| `ESO_COMP_GAIN` | 0.5 | 每次 +0.25,过冲则回退 |
| `ESO_COMP_LIMIT` | 500 码(≈3%) | 起步保守 |
| 门控 | `\|速度误差\| < 50 deg/s` 且输出未饱和 | 防与主控抢输出。**与南理工不是同款(更正)**:他们门控的是 `\|ω_measured\| ≤ eso_omega_gate` 与 `\|α_ref\| ≤ eso_alpha_gate`(绝对转速 + 参考加速度,见 §2.2),我们用跟踪误差——语义是"模型可信时才信 ESO"。差别只在"高速匀速瞄准"一档:我们门开、他们门关。**不做任何底盘侧冻结**,理由见下 |

> **门控定案(2026-11-12 三审,推翻二校的"底盘加减速冻结"方案)**:二校曾主张按底盘加/减速冻结 ESO,
> 三审推翻。依据是被控对象方程本身——世界系 ESO 的模型 `J·α_world = Kt·u − τ_f(ω_joint) − τ_cable` 里
> **没有 α_chassis 项**:底盘加减速只通过 ω_joint 的变化改变摩擦扰动,而摩擦残差正是 z3 应该估计并
> 补偿的东西(手写前馈覆盖标定部分,z3 补残差)。"z3 被 α_chassis 污染"这个前提不成立。
> 逐工况检验速度误差门控的行为,恰好全部正确:
> - **小陀螺启动/停止**(瞄准保持):速度误差≈0 → 门开。此时摩擦爬升最快、残差最大(B 未重标前甚至过补),
>   ESO 恰好应该工作;任何底盘冻结方案都在最需要时把它关掉;
> - **推杆瞄准/跟随追赶**:速度误差大 → 门关,防抢输出(南理工原意);
> - **稳态(含匀速小陀螺)**:门开,补线缆/滑环周期扰动(P5 主目标)。
>
> 三校的两点事实修正是对的(①`CHASSIS_ROTATE` 的 wz 直接赋值、无斜坡;②指令差分只在阶跃那一拍非零,
> 而轮速环建立真实加速需 50~200ms 量级),但其替代方案 A(模式沿定时冻结)/B(关节加速度门控)一并否决:
> B 在推杆工况与速度误差门控冗余(推杆时 α_joint 同样尖峰),A/B 唯一新增行为都是"启动段冻结"——
> 即上述有害行为。结论:**底盘侧门控整体不必要,也不应实现。**

| 判据 | 目标 |
|---|---|
| 稳态残差 | 再降 ≥30%(相对 P3 后) |
| 匀速小陀螺电流 | 波动峰峰值下降(线缆扭力被吃掉) |
| 无高频啸叫/无过冲 | 主观 + out 频谱无新峰 |

> **顺序纪律(P5 的前置条件,勿省略)**:P5 **必须在 P2/P3 标定定案后**做,且开启 ESO 前后要留
> "手写前馈(已标定)+ ESO 关" 这一组对照。原因:z3 会吸收手写前馈的**残差**——若标定本身偏了,
> ESO 会把误差吃进去、整体表现照样变好,于是你既看不出标定错了,也把观测器当成了"遮羞布"。
> 判据里的"相对 P3 后"就是这个意思:P5 的收益只能建立在标定正确的前提上。

**回退**:`ESO_COMP_GAIN=0`(观测器可保留但不作用)。

### P6 力矩上限与小陀螺上限重定(≈30 分钟)

## 8. 风险矩阵

| 风险 | 触发条件 | 表现 | 处置 |
|---|---|---|---|
| 库仑项零速抖 | EPS 过小 | 静止嗡嗡/微抖 | EPS 30→50;仍抖则 COULOMB 减半 |
| α_ref 前馈过激/噪声 | 参考差分未滤波或 J 标定偏大 | 高速段啸叫/过冲 | α 低通 0.2→0.12;α 限幅降到 600;或宏回 0 |
| ESO 与主控抢输出 | 增益过大 | 低频摆动/过冲 | GAIN 回退;ω0 降到 20 |
| ESO 门控过紧 | 速度误差阈值过小,或堆叠多余门控条件 | ESO 长期不作用,P5 判据测不出改善 | 阈值 50→100 deg/s;门控只保留"速度误差+未饱和"两项,禁止堆底盘侧条件 |
| ESO 与手写前馈重复补偿 | 两者都在补摩擦 | 稳态反向偏差 | 门控收紧;或先关手写 B 项只留库仑 |
| 3A 上限不够 | 小陀螺提速 | 自转跟不上 | 实测上限入 DEC 台账,取舍队伍拍板(P6),勿默认降速 |
| 标定受前馈污染 | 忘了关 FF | 拟合结果全错 | P2 步骤 1 必须先置零,记录里写明 |
| P2 稳态 offset 误判为故障 | IL 小,摩擦经 P 通路建立 | 扫掠时 offset≈1.5° | 正常现象,见 P2 方法 A 步骤 2 |
| J 标定结果异常 | 扫掠数据无激励混入拟合 | J≈0 或为负 | J 只用方法 B(底盘静止+阶跃激励)的数据 |
