## 0. 一句话结论

跟随与小陀螺缺的**不是新结构,是三件事**:
①小陀螺启动/停止的 **wz 阶跃**——300°/s 直接踢四轮,是全车最猛的机电瞬态,且"旋转加斜坡会振荡"
的旧结论是在没有 `est_wz` 的时代下的,从未复验;
②跟随三分项里,**阻尼项(3Hz 滞后的 offset 差分)与前馈项(无滞后的 Gyro[2])是同一个物理量的两种估计**,
起步段互相重复、ecd 量化噪声直接进差分——阻尼项的真实独立价值只在收尾刹车段;
③follow↔rotate 模式切换无连续化(川大教训在这条通道上还没落地)。

## 3. 本车问题归因

### 3.1 小陀螺启动 = 全车最猛的机电瞬态

wz 0→300°/s 阶跃 × 力臂 340mm → 四轮目标速度阶跃(等效 ±2112 mm/s 级),电流冲击 + 打滑 + 机械冲击;
退出反向同理。而"旋转指令刻意不加斜坡(会引发振荡)"的历史结论,**当时既没有 est_wz 也没有高分辨率
观测手段**——斜坡本身不引发振荡,引发振荡的是斜坡与速度环增益的相互作用,现在有 est_wz 可以看见了。
P3 复验:真实则记 DEC,不真实则删旧结论。

### 3.2 跟随三分项的信息冗余:damp 是 ff 的滞后版

恒等式:`offset_rate ≈ ω_gimbal − wz_actual`(忽略量化与低通)。于是:

- **起步/匀速段**:云台转、底盘未跟上 → `offset_rate ≈ ω_gimbal` → damp ≈ 0.9×0.9×ω_gimbal,
  与 ff **同向且重复**(约为 ff 的 81%,还多 3Hz 滞后);
- **收尾段**:云台停转,ff=0,offset 从峰值回落 → offset_rate 反向 → damp 反向刹车——**这是它唯一的独立价值**;
- ecd 量化噪声直接进差分(靠 SPD_MIN=3°/s 门限兜底,门限以下的噪声仍被 3Hz 低通部分保留)。

结构性问题:阻尼项想要的是"底盘落后云台的速度",却用了一个滞后 + 含噪的间接估计。**est_wz 就位后,
直接量是 `ω_gimbal − est_wz`**——无 ecd 量化噪声、无 180° 折返尖峰、无 3Hz 滞后。P2 的结构性改造就基于此。

### 3.3 offset 单圈角差的 180° 折返尖峰

offset 用 ecd **单圈**角差:云台相对底盘真实角度越过 ±180° 时,offset 突跳 360°(方向翻转)。
跟随律走最短路径,跳变后反向追是**正确行为**;但 `chassis.c` 的 offset 差分**没有任何折返检测**:

```c
float rate = (chassis_cmd_recv.offset_angle - offset_last) / dt_sec;   // 无折返处理
```

跳变拍 = 360°/5ms = **72000°/s**;经 α=0.1 低通一步后仍 7200,乘 DAMP 0.9 = **6480°/s**,
而输出限幅只有 ±`CHASSIS_ROTATE_SPEED`(300),且低通每帧只衰减 10%——从 6480 衰减到 300 以下约需 29 帧(≈145 ms),**一次折返 = 输出饱和约 145 ms 的持续假踢**,比"饱和一帧"更严重。
换 `ω_gimbal − est_wz` 输入后此问题消失(P2 顺带收益);若保留旧输入,必须加折返检测。

### 3.4 线性/平方律分段点的增益 2 倍跳变

```
eff < 5°:  wz_pos = KP × LIN_RANGE × eff   → 导数 KP×5      = 7.5 /deg
eff ≥ 5°:  wz_pos = KP × eff²              → 导数 2×KP×eff   = 15 /deg (@5°)
```

**5° 处输出连续**(1.5×5×5 = 1.5×25 = 37.5,两式相同),但**增益从 7.5 跳到 15**。
offset 在 4.9°→5.1° 之间微动时,底盘响应的"刚度"翻倍——这是末端小幅来回摆的**结构性来源之一**,
与 DAMP 无关。

**处置分两级**:

1. **回避(只能挪工作点)**:调大 `LIN_RANGE`,让常规跟随整体落在线性段。代价是远距离(>LIN_RANGE)
   追赶变慢。**注意这不解决结构问题**——2 倍增益跳变是"线性 + 平方律"这对组合的固有属性,
   换个 LIN_RANGE 只是把跳变挪到别处,工作点一旦越过边界照样撞上。
2. **根治(C¹ 拼接)**:要求分界点处**输出与导数同时相等**。可行形式:

   ```
   eff < L:   wz_pos = KP·L·eff
   eff ≥ L:   wz_pos = KP·L·eff + KP·(eff−L)²
   ```

   在 eff=L 处:值 = `KP·L²`(与线性段相同),导数 = `KP·L`(与线性段相同)→ **增益连续,无跳变**。
   远处二次项接管,仍保留"角度越大越猛"的原意(2L 处 = 3KP·L²,介于线性外推 2KP·L² 与原平方律
   4KP·L² 之间,比原来软一档)。

   > 等价写法 `KP·(eff² − L·eff + L²)`。**常数项 `+KP·L²` 不能省**——只写
   > `KP·eff² − KP·L·eff` 在分界点会归零,输出直接掉下去,比跳变更糟。

**什么时候动**:先跑 F1 基线,看波形确认摆动真的发生在 offset≈5° 附近。不在此处则本条只是理论隐患;
确实骑在分界点上就直接上方案 2,别用方案 1 拖——**方案 1 治标不治本**。

### 3.5 模式切换无连续化

follow→rotate:wz 从 ≈0 跳 ±300;rotate→follow:从 300 跳到跟随律瞬时值(≈0 附近)。双向阶跃,
与川大教训直接对应。

| 平移叠加 | 斜坡期间平移不失控(推杆直行 2 m 偏移与 F4 同档) |

**回退**:`CHASSIS_SPIN_RAMP_TIME=0`(恢复阶跃)。

### P4 模式切换连续化(≈1 小时)

切换瞬间(follow↔rotate↔zero)**wz 目标从当前 est_wz 经同一条斜坡通道过渡到新模式目标**,不做直切;
判据:F5 基线的 est_wz 突变与电流冲击下降 ≥30%;切换到跟随的首秒收敛不劣化。
**回退**:直切恢复。

### P5 小陀螺转速慢闭环(可选,≈1.5 小时)

est_wz 比例微调:`wz_cmd += K · (wz_target − est_wz)`,**限幅 ±10% 目标值、带宽 ≤1 Hz**;
打滑保护:`|est_wz − wz_cmd| > 30%·wz_target` 时冻结修正(轮速逆解在打滑时失真,见底盘-V4)。

| 判据 | 目标 |
|---|---|
| 三档自转 est_wz 波动峰峰值 | 比开环下降 ≥30% |
| 平移叠加 | 不劣化 |
| 打滑注入(人为推车横移) | 修正被冻结,无正反馈疯转 |

**回退**:`CHASSIS_SPIN_CLOSEDLOOP_EN=0`。

### P6 回归与归档(≈40 分钟)

F1~F5 全量复测与基线对比;结论写入《本车调参结论》§3/§4、《参数证据表》、RM_DEVLOG;
