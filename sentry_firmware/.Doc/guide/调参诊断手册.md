# 调参诊断手册(症状 → 参数/变量 → 工具 → 判据)

> 用法:先查"症状"行 → 采对应预设 → 按"判据"分支 → 只动表中列出的参数,一次一个,带证据等级。
> 证据等级与完整踩坑:`.Doc/spec/参数证据表.md`、`.Doc/spec/本车调参结论.md`(改前必读)。
> 本文只做"索引+判据",不复制参数值——值以 config 注释为准。

## 0. 通用动作(任何症状第一步)

1. `node tools\doctor.js` —— 链路体检(桥接/固件身份/供电/关键指针),排除"读数污染"。
2. 确认固件身份:ELF sha256 与板上向量表一致(doctor 第 5 步);不匹配 = 烧的不是这份代码。
3. 采集:`node tools\pitch_trace.js --preset <症状预设>`;离线:`analyze_var_trace.py --all`。
4. **一次只改一个参数**;改前在 DEVLOG 记"预期现象",改后回填"实际现象"。

## 1. 云台 yaw

| 症状 | 预设/工具 | 关键变量 | 分支判据 → 参数 |
|---|---|---|---|
| 往复抖动(松杆不停) | `--preset yaw_oscillation` | `gimbal_imu_data->YawTotalAngle` vs `gimbal_cmd_recv.yaw` | ref 台阶而 fb 平滑=输入问题(查 cmd 斜坡);fb 自身往复=控制环:优先 `YAW_SPEED_KD`/调度 `UpdateYawDamping`,其次 `YAW_SPEED_KP` |
| 恒速跟踪滞后(推杆拖) | 同上 | ref-fb 恒差 | 前馈未生效:查 `YAW_REF_FF_MAX_DELTA`(满杆 Δref>阈值→被判跳变清零,DEV-20261122-04 教训)与 `YAW_REF_FF_GAIN` |
| 大角度甩动发钝 | 同上 | `yaw_motor->...Output` 顶格 | 输出限幅/电压域:`YAW_ESC_OUT_MAX`、`YAW_SPEED_KP_HIGH` 调度(电压模式) |
| 解锁甩向固定角 | `doctor.js` + RTT | `robot_state`、`ins_state.Yaw` | 零位:`YAW_CHASSIS_ALIGN_ECD`(拆装传动必重标);标定走 `CalibTrigger`/`gimbal_recenter` |
| 小陀螺转速不符 | RTT `[chcal]` | `chassis_cmd_recv.wz` 实测 | `CHASSIS_ROTATE_SPEED`(实测 390 触顶,300 留余量);轮径 `CHASSIS_WHEEL_RADIUS` 改动会等比放大一切速度 |

## 2. 云台 pitch

| 症状 | 预设 | 关键变量 | 分支 → 参数 |
|---|---|---|---|
| 推杆顿挫(一顿一顿) | `--preset pitch_stutter` | fb 锯齿+out 台阶 | out 与杆量 70Hz 同步纹波=输入台阶→`PITCH_REF_FF_LP` 升;out 锯齿爬升+fb 平台=stick-slip→查摩擦/`PITCH_SPEED_KI`(DEC-004:三轮盲改全否决,先取证) |
| 偶发抖动 | 同上 | fb 噪声底 | 反馈:`ins_state.Gyro[0]`(欧拉换算已入代码);噪声大→反馈滤波,勿先动 Kp |
| 重力补偿不对称(抬/降力度差) | 静止读 out | `pitch_motor->...Output` 稳态 | `PITCH_GRAVITY_FF_GAIN` 符号/幅值(宁欠勿过) |

## 3. 底盘

| 症状 | 预设 | 关键变量 | 分支 → 参数 |
|---|---|---|---|
| 不跟随云台/画龙 | `--preset chassis_follow` | `chassis_cmd_recv.wz` vs `est_wz` vs `offset_angle` | est 正常 cmd 异常=cmd 侧;两者都稳但车不转=执行侧;跟随律参数 `CHASSIS_FOLLOW_*`(软死区/平方项) |
| 平移速度快/慢 25% | `--preset chassis_power` | `est_vx` vs `chassis_cmd_recv.vx` | `CHASSIS_WHEEL_RADIUS`(75mm 实测修正,DEV-20261109);改轮径必重测 |
| 触 6000RPM 限幅 | 同上 | `vt_*` 顶格 | 自转+平移叠加;力臂/`CHASSIS_ROTATE_SPEED` 复核 |
| 功率/缓冲异常 | RTT `[chcal]` | power=-1 | 裁判 0x0202 未上线(-1 是占位),不是功率 bug |

## 4. 发射/热量

| 症状 | 工具 | 判据 → 参数 |
|---|---|---|
| 连发射速不符 | RTT `[heat]` 摘要 | 摊平律输出 vs 实测弹速;`SHOOT_RATE_DEFAULT`/档位映射(`cmd_fire_tier_rate`) |
| 守卫永久锁枪 | `[heat]` 状态 HOLD | `HEAT_GUARD_ALLOWANCE_ENABLE=0` 时台架额度恒 0(比赛必须置 1);或裁判离线判定窗 |
| 单发卡弹/双发 | RTT + 台架 | `SHOOT_ONE_BULLET_DELTA_ANGLE`(360/7 输出轴 deg)与 `LOADER_ANGLE_TOL_DEG`;堵转判据 `LOADER_JAM_*` |

## 5. 电机/链路层

| 症状 | 工具 | 判据 → 处置 |
|---|---|---|
| 电机不出力但反馈正常 | `motor_health` 预设 + RTT | 先查在线(daemon)→使能→**0x2FE 电流帧:RoboMaster Assistant"电流环"开关未开**(RM 台账定案,勿再查代码) |
| 某轮持续离线 | doctor 指针 + CAN 丢帧计数 | CAN 编号/拨码;`can_add_filter` bank 分配;TX 邮箱/丢帧计数遥测 |
| 遥控断流误判 | RTT + `cmd_watchdog` 阈值 | 断流 200ms 阈值与 DBUS 帧周期;`cmd_watchdog_feed` 未喂=帧校验拒绝(非法帧清零不喂狗) |
| USART 口丢数据 | `usart_get_overrun_count` | 消费追不上(RING 1024 ≈11ms);提高消费频率或降波特率 |

## 6. 标定流程(电机速度环)

1. 采集:`pitch_trace.js --preset chassis_power`(或自定义四轮电流/速度),覆盖
   ≥3 个恒速段 + ≥2 个阶跃 + 一段静止。
2. 拟合:`python tools\motor_calib.py <csv> --target vt_lf --speed ... --u ...`
   输出 K(稳态增益)、τ(63.2% 时间)、σ(静止噪声)与 Kp/Ki 初值。
3. 落地:初值只作量级参考,按"0.1 步长单变量"实车复核;结果带 `[标定脚本+日期]`
   证据标记写回参数证据表,config 行内注释保留一句话依据。

## 7. 反模式(历史否决,勿重试)

- 盲改三轮以上不取波形(DEC-004)。
- `memory.read` 运行期读参(DEV-20261112)。
- 用"暂停式读数"的波形调 Kd(现象被探针污染,DEV-20261112)。
- 跨工程照抄跃鹿 `wz=4000` 类无量纲魔数。
- 电流模式 0x2FE 不出力时排查固件(开关在 Assistant)。
