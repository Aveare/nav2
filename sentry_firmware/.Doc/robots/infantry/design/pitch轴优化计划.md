## 2. 结构变更的失效清单(先处置,再调参)

### 2.1 IMU 轴向与安装方向(错了会飞车)

速度环现在吃 `Gyro[0]`(芯片 X 轴),角度吃欧拉 `Pitch`——两者都建立在**旧结构的 IMU 安装姿态**上。

- 手转 pitch 单轴,**看哪个 Gyro 通道响应最大**;若不再是 `[0]`,速度反馈指针与 `GYRO2GIMBAL_DIR_*` 都要改;
- 历史留有一个未解张力:DEV-02 分析指出 `Gyro[0]` 是欧拉 roll 轴、**不含 pitch 角速度**,但 DEC-004 回滚到
  `Gyro[0]` 后实车更顺。新结构下该结论**不可照抄**,要用本次核验重新裁决;
- 若出现"正反馈疯甩",立刻方向取反(DEV-02 留的开关)。

### 2.2 重力矩与质心(决定 IL、MaxOut、前馈幅值)

`τ_g(θ) = m·g·L·cos(θ − φ)`,`m`、`L` 全变。量级估算(用于判断 MaxOut 是否够):

```
C620:±16384 码 ↔ ±20 A;M3508 Kt ≈ 0.3 N·m/A
→ MaxOut 4000 码 ≈ 4.88 A ≈ 1.47 N·m
→ 若新结构 m≈1.2 kg、质心距轴 L≈0.10 m,则 τ_gmax ≈ 1.18 N·m(余量仅 25%)
```

**结论:新结构若更重或质心更远,MaxOut 4000 会不够**;这条必须用 P2 标出来的 A 值复核,
而不是沿用旧值(旧结构当时没算过这笔账)。

### 2.3 转动惯量

变 → 速度环带宽、角度环 Kp、ref 前馈手感全变;也决定是否值得上惯量前馈。

### 2.4 结构刚度与柔性模态(新结构最大的未知)

开源(诺丁汉联队"电控反玄学")给的判据:双惯量系统柔性模态

```
ω_f ≈ √( k_t · (1/J_m + 1/J_l) )
```

`k_t` 是电机与负载间的等效扭转刚度。**新材料/打印件/薄壁件会显著降低 k_t → ω_f 下移**。
一旦 ω_f 落进控制带宽(我们速度环实测有效带宽约 10~30Hz),表现就是"电机先动 → 结构扭 → 回弹 →
控制器再加力"的正反馈,即"抖得像里面住了东西";此时**继续加增益只会给共振喂能量**。

所以新结构必须先做一次**共振辨识**(P1-B7),再决定 P4 用哪种手段:低通降带宽 / 二阶陷波 / 改机械。

### 2.5 机械限位与传动间隙

- 限位:`PITCH_MAX/MIN` 从未实测;新结构撞硬限位会顶电机或拉坏机构;
- 间隙:新联接方式改变回差 → 小步爬行、换向冲击,拟合时表现为摩擦模型的非线性残差。

### 2.6 走线

线缆长度/固定点变 → 转矩偏置与"上抬/下抬不对称"幅值变,新的常值偏置会进 P2 拟合的 B 项。

## 3. 开源实现对照(源码/实测级,只列 pitch 相关的)

| 来源 | 具体做法 | 对本车的判定 |
|---|---|---|
| **rm-controls** `gimbal_base.cpp` | `gravityFeedForward()`:把重力向量变换到 pitch 关节子连杆系,`τ = -(mass_origin × gravity).y`;`mass_origin` 存的是**质量×质心位置(一阶矩)**,所以**不需要单独称质量**;带 `enable_gravity_compensation` 开关;质心只取 x、z 分量 | **采纳思路**。我们的 `A·cos(θ−φ)+B` 拟合同样只辨识"一阶矩×g"这一个标量,比量质量和质心更省;B 项额外覆盖线缆偏置(rm-controls 无此项) |
| **南理工 LQR+ESO** | `τ_ff = J·α + B·ω + τc·tanh(ω/ε)`;ESO 补残差;软/硬/斜率三级限幅 | **摩擦项采纳(P5)**;ESO 留作 P6 可选(pitch 有减速箱与间隙,先解决重力与共振) |
| **诺丁汉联队 双惯量分析** | `ω_f ≈ √(k_t(1/J_m+1/J_l))`;结构越软频率越低、越易与控制带宽重叠;"继续加增益=给共振喂能量" | **采纳为设计判据**:新材料→刚度未知→必须先辨识(§2.4 / P1-B7) |
| **RM2026 摩擦轮振动→IMU 姿态异常** | 陷波 vs 低通的量化对比:100.85Hz、Q=30 陷波把干扰压到 14.7%;20Hz 一阶低通压到 13.0% 但给 5Hz 信号带来 0.24 rad 相位滞后;**关键提醒:低通要加在"输入的高频干扰"上,不是加到"输出的低频假姿态"上** | **采纳为滤波位置判据**:我们的异响证据是"输出力矩纹波激励结构",属执行侧 → 维持输出低通是对的;但若新结构是**测量噪声**型抖动,应改在反馈通道滤,两者不要混 |
| **伺服行业实践(扫频+陷波)** | 扫频找共振峰 → 按中心频率/深度/Q 设陷波 → 再重新整定增益;陷波对频率漂移敏感;降增益只是把问题藏起来 | **采纳为 P4 流程**;是否实现二阶陷波取决于 P1-B7 结果(当前 `controller.h` 只有低通,无陷波) |
| 复旦/川大滑模 | 与 yaw 同:结构等价于 PD+边界层 | **否决**(同 yaw 结论) |

**与 yaw 的关键差异**:yaw 轴竖直、无重力项,pitch 的负载随角度变化近一个数量级(水平最大、垂直最小)。
所以 pitch **不能用"固定前馈"**,必须是随角度变化的模型前馈;IL 的物理含义同样是"扛最大重力矩",必须按标出的 A 重算。

### P2 重力模型标定(核心,≈1 小时)

**方法(闭环保持,逐角度读稳态电流)**

1. `PITCH_GRAVITY_FF_GAIN=0`(前馈关闭),角度环/速度环保持现状;
2. 从下限到上限**每 5° 一档**(≈8~9 档),每档到位后静置 3s;
3. 记录每档 `Pitch`(deg)与速度环稳态 `Output`(C620 码);每档重复 3 次取平均,记录环境温度;
4. 最小二乘拟合 `I(θ) = A·cos(θ − φ) + B`:
   - **A** = 最大重力矩对应的电流码(⇒ `τ_gmax = A/16384×20×0.3` N·m);
   - **φ** = 质心相位(理论 0°;偏离说明有配重或线缆拖拽);
   - **B** = 常值偏置(线缆扭力/零点摩擦,不是重力);
5. **交叉校验**:`τ_gmax` 与"新结构质量 × 质心距"估算比,差 30% 内算合理;
   同时检查 `IL=1200` 与 `MaxOut=4000` 是否仍覆盖 A(不覆盖就先改这两个再继续)。

**判据**:R² > 0.95;φ 落在 ±10° 内;A 的 3 次重复波动 < 10%。
**偏离处置**:R² 低 → 多半是传动间隙/死区造成的非单调,先在每档"正反两个方向各到位一次"再取平均。

### P3 重力前馈落地(≈40 分钟)

```c
/* pitch_deg 必须取 IMU 欧拉角 Pitch:重力是世界系方向的量,电机编码器角在 IMU 侧装/翻装/零位偏移时
 * 与"重力方向"不等价;用编码器角做 cos 自变量,侧装时会直接算错相位。 */
float g = PITCH_GRAVITY_A * cosf((pitch_deg - PITCH_GRAVITY_PHASE) * DEGREE_2_RAD) + PITCH_GRAVITY_OFFSET;
LIMIT_MIN_MAX(g, -PITCH_GRAVITY_FF_LIMIT, PITCH_GRAVITY_FF_LIMIT);  // 前馈不受速度环 MaxOut 钳制,必须自带限幅
pitch_gravity_ff = PITCH_GRAVITY_FF_GAIN * g;
```

> **前馈绕过了 MaxOut(代码事实)**:`DJIMotorControl` 里 `CURRENT_FEEDFORWARD` 是在速度环输出**之后**加到
> `pid_ref` 上的,所以 `MaxOut=4000` 管不到前馈——总电流可以是 4000 + FF。`PITCH_GRAVITY_FF_LIMIT` 不是可选项,
> 取 `1.2 × |A|` 起步(如 A=1000 → 1200 码 ≈ 0.44 N·m),防止拟合偏差或相位错误时灌进过大电流。

GAIN 从 **0.5** 起(标定值先折半,避免拟合误差被全额放大),逐档 0.6/0.8/1.0。

| 判据 | 目标 |
|---|---|
| **符号检查(首档必做)** | 施加前馈后稳态电流**下降**;若**不降反升(甚至下坠加速),立即 GAIN=0 并查符号/相位** |
| 各角度稳态电流 | 平均下降 ≥50%(重力被前馈直接顶掉,不再靠积分) |
| 积分限幅 | 可从 1200 降到 600(不再兼职扛重力) |
| 回水平到位 | 残留角 < 0.5°,不再需要 DeadBand 兜底 |
| 到位过冲 | 不增加(前馈只改变平衡点,不改变动态) |

**回退**:GAIN=0(模型参数保留)。

> 说明:拟合时 A 用**带符号的电流**回归,符号会被自动吸收进 A(电流为负表示该方向出力)。
> 但"符号是否被正确吸收"只能在首档用上面那条**稳态电流下降**判据显式验证,不能默认成立——
> 符号反了等于助推下坠,是本计划唯一可能伤到机械的失误方式。

### P4 摩擦项与滤波重定(≈1.5 小时,依赖 B7)

**P4-0 摩擦参数标定(先做,否则 PITCH_FRICTION_B/COULOMB 无处产生)**

P2 的静态保持是 ω≈0,只能给出"重力 + 静摩擦",**粘性项 B 测不出来**。补这一步:

1. 前提:重力前馈已落地并验证(P3 通过),`PITCH_FRICTION_B=0`、`PITCH_FRICTION_COULOMB=0`;
2. 从中位(0°)起,用**恒定杆量**给几档低速匀速:关节目标速度约 **3 / 5 / 10 / 20 deg/s**
   (遥控杆量与 `PITCH_REF_FF_MAX_RATE=60°/s` 的映射已知,按比例给);
3. 每档持续 ≥1.5s 稳态,**上下两个方向各一次**(上限 ±25° 内往返,避免撞限位);
4. 每档记录 `omega_joint`(电机转子速度 ÷ 19)与稳态 `out`,**减去 P3 的重力前馈值**后得到纯摩擦力矩;
5. 最小二乘 `I_f(ω) = TAU_C·sign(ω) + B·ω`(或直接对 `I_f` 拟合 `b·ω + a·sign(ω)`):
   - **截距 a = 库仑项**、**斜率 b = 粘性项**;
   - 双向截距差 `(a+ − a−)/2` = 传动不对称量(可作单独参数)。

**判据**:R² > 0.90(低速档摩擦非线性强,不必要求 0.95);双向截距差 < 25%;四档中有 ≥3 档的残差 < 15%。

**P4-1 路线选择(先看 B7 结果,不要先改参数)**

| B7 结果 | 路线 |
|---|---|
| f_res > 40Hz 或未见明显峰 | 维持输出低通,只重扫 RC(0.006/0.010/0.014 三档),按"上抬异响是否消失 + 是否发肉"取舍 |
| 10Hz < f_res < 40Hz(落入带宽) | 先降速度环 Kp 试(f_res 处增益压低),仍响再上二阶陷波(需批准:新增滤波器,`controller.h` 目前只有低通) |
| f_res < 10Hz | 软件已难救,**先反馈机械/结构**(加筋、换材料、缩短悬臂),软件侧只能大幅降带宽 |

**P4-2 摩擦项落地**(与 yaw 同一套,但注意减速比):

```c
tau_f = B_joint * omega_joint + TAU_C * tanh(omega_joint / EPS);   // omega_joint = 转子速度 / 19
```

pitch 关节经 19:1 减速,关节转速低、力矩大 → **摩擦的库仑项占比更高**,不能照搬 yaw 的 B 值。

| 判据 | 目标 |
|---|---|
| 小步爬行(30° 小步) | 无"先顿一下" |
| 静止 out 抖动 | 峰峰值不增加超过 20% |
| 上抬异响 | 消失且不出现新的高频声 |

### P5 惯量与增益重整(≈40 分钟)

1. 新惯量下重定速度环 Kp(从 50 起,按"阶跃响应无过冲、无啸叫"双向试)、Ki(先 10,喘振→5,延迟→15);
2. 角度环 Kp(从 8 起),DeadBand 视极限环调整;
3. 惯量前馈可沿用 yaw 的 α_ref 思路(宏已存在),但 pitch 目标角速度有 150°/s 上限,前馈收益低于 yaw,**优先级最低**。

**判据**:B1/B2/B5 全部回到基线水平或更好;上抬无啸叫;满杆阶跃超调 < 10%。

### P6 极限、安全与可选 ESO(≈40 分钟)

1. 撞限位测试:满杆上下,确认目标角钳位生效、不撞机械;
2. 堵转/过流:人为卡住 pitch 1s,确认无过热、无失控;
3. (可选)ESO:仅当 P3~P5 后仍有随角度变化的稳态残差时启用;门控沿用"速度误差 + 未饱和",
   **不要引入底盘侧门控**(yaw 已定的结论:`J·α_world` 模型里没有 α_chassis 项)。

### P7 回归与归档(≈1 小时)

B1~B7 全跑一遍,与 P1 基线逐项对比;结论写入《本车调参结论》§2、《参数证据表》、RM_DEVLOG 新 DEV 条目;
被否决的路线进 DEC 台账。

## 8. 风险矩阵

| 风险 | 触发条件 | 表现 | 处置 |
|---|---|---|---|
| IMU 轴向判错 | 新结构改了 IMU 安装 | 正反馈疯甩/抖动加剧 | 立即方向取反;重做 B1 |
| 限位未测就满杆 | 跳过 B2 | 撞硬限位、顶电机 | B2 前置,断电手推 |
| 重力前馈盲上 | 不标定直接给 GAIN | 手感更差且无法归因(DEC-004 已否决一次) | 必须 P2 先行 |
| **前馈符号/相位反了** | A 符号或 φ 错 | **助推下坠**(比不加更危险) | 首档判据"稳态电流必须下降";`FF_LIMIT` 兜底 |
| **前馈绕过 MaxOut** | 误以为 4000 是总上限 | 实际总电流 = 4000 + FF,可能过大 | `PITCH_GRAVITY_FF_LIMIT` 必须设(代码事实,见 P3) |
| **B7 读不到振动** | P0-2 把 extra 提前改成电流码 | 敲击时四列全是 0,无法辨识 f_res | P1 保持 extra=Gyro[0];优先用 Ozone 看 1kHz IMU |
| 新结构刚度低 | 打印件/薄壁/悬臂长 | 5~30Hz 共振,越加增益越抖 | B7 辨识;降带宽/陷波/改机械 |

| 低通加错位置 | 把测量噪声当执行纹波 | 延迟增加、异响不减 | 先判来源(§3 RM2026 那条) |
