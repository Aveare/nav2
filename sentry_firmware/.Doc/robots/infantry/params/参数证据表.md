> **缺口最大的一块**。三项堵转阈值全是估的,而它们直接关系"卡弹时会不会烧电机"。建议台架做:堵住拨盘,记录稳态电流/转速随时间,取值。
> **硬件缺口(2026-11-26)**。右摩擦轮 C620 经 CAN1/CAN2 全 ID 扫描均无反馈(`origin/sentry` DEV-20261126-32/33/35):

> 软件无法修复;修复前两轮到速互锁恒不通过,单发/连发会被 fail-closed 拦住。

## WHEEL_BASE

- * 测量:前后轮沿车长方向的最外缘≈轮心平面(麦轮滚子包络极值在轮心处),卷尺读 500,
- * 滚子离散误差 ±15mm;原值 300 为设计值,与实测差 40%,本日用户拆量解除"轴心不可达"。
- * 与 TRACK_WIDTH 一起经 (半轴距+半轮距)×0.7071 得自转力臂 340mm(原 212),影响小陀螺转速与跟随追赶速度;
- * **不影响平移速度**(平移项不乘力臂)。
- * 改后行为预期:同一自转指令下车身实际转速约 +60%(此前力臂被低估、轮速指令给少了),
- * CHASSIS_ROTATE_SPEED 体感需重新对;自转叠加平移时更易触 CHASSIS_MAX_MOTOR_RPM 限幅。


## TRACK_WIDTH

- * **两个方向的换算不对称,别混用**:横向极值在滚子端面(必须减轮宽),纵向极值在轮心平面(不减)。
- * 力臂用 (轴距/2+轮距/2)×0.7071 近似,与真实对角线 √(250²+230²)=340 差 <0.2%,近似成立。


## CENTER_GIMBAL_OFFSET_X

- * 本义:描述云台旋转中心偏移;本车实车未量,当前兼作"小陀螺平移漂移"的补偿旋钮。
- * 试过 -20、-40 均无改善(DEV-20261103-02/-03),回退 0;0 时表现为纯自转缓慢向右漂。
- * 若漂移加重:优先用 CHASSIS_TRANSLATE_BIAS_ANGLE 补偿,本参数保持 0。


## RADIUS_WHEEL

- * **修正记录:原值 60(直径 120)与实际不符,导致实车一切速度比指令快 25%。**
- *   小陀螺:指令 300 deg/s,实际跑 375;平移:指令 1500 mm/s,实际 1875。
- *   裁判系统看到的 30W 对应的也是 375 deg/s(转子 3359 RPM);
- *   修正后同一指令为 300 deg/s(转子 2687 RPM),功率约 22W 属正常。

## CHASSIS_MAX_MOTOR_RPM

- * 3508 转子机械上限 469rpm×19 = 8911 RPM,6000 为 67%;7000 为 78%。
- * 大 → 允许更高轮速,但接近空载转速时扭矩骤降、电流环易饱和;
- * 小 → 高速平移被整体削速(四轮等比例缩,不改变方向)。
- * 2026-11-16 架空实测(F2 转速相容性,`build/chassis_f2_airborne.csv`):
- *   单独自转 300°/s 需 4299 RPM、单独满速平移 1500mm/s 需 2566 RPM,
- *   两者叠加需 6865 RPM —— 6000 使"下挡小陀螺 + 右杆推到底"被削 12.6%
- *   (实测轮速顶在 6073/5994 RPM = 限幅 36000 deg/s,est_vx 1278、est_wz 288,
- *   vx/wz 比值 4.90 与指令 5.00 一致 → 等比例限幅本身正常,只是整体降速)。
- * 取 7000 时"满速平移 + 满速自转"恰好不被削(6865<7000,余量 2%);
- * 回退路径:若高速自转+平移叠加体感"变沉"明显,再改回 7000;8000 需先确认 24V 与温升余量。
- * **2026-11-26(DEV-20261126-25)曾保持 6000,不走"抬 7000"路径**:改为小陀螺模式
 *   平移限 1200 + 自转轮速余量 5600 重定心(见下方 `CHASSIS_SPIN_MAX_SPEED` 节)。
 *   1500+300 需 6865 rpm、1500+350 需 7582 rpm,6000 下不可能全给。
- * **2026-11-26(DEV-20261126-27)按用户要求放宽到 7000**:小陀螺平移测试需要更高
 *   自转峰值;7000 = 78% 机械上限,接近空载扭矩骤降、电流环易饱和,长时间满载需
 *   复测电机/电调温度。1500+300(6865)重新允许;小陀螺平移仍限 1200,自转软限 6800。

## CHASSIS_VX_BRAKE_RAMP / CHASSIS_VX_BRAKE_JERK

- * 只在减速段(松杆收油或反向扳杆)生效;加速段仍 5000/20000,起步手感不变。

## CHASSIS_FOLLOW_KP

- * 律:wz_pos = KP × err(err 已扣死区),不再有"小角度线性/大角度平方"两段。
- *
- * **为什么不用官方的 40**:官方 Development-Board-C(2020 standard_robot)的
- * `CHASSIS_FOLLOW_GIMBAL_PID_KP` 是 40 (1/s)、纯 P、输出限幅 6 rad/s≈344°/s。
- * 那个值配的是 4m/s、力臂 0.2m、500Hz 控制周期的轻车;本车力臂 0.34m、任务 200Hz,
- * 且 2026-11-20 实测本车跟随存在 **3.16 Hz 自激**(cmd_wz ±6°/s,偏角仅 ±0.8°),
- * 正好发生在旧律斜率 ≈11 (deg/s)/deg 的工作点。**照抄 40 会把穿越频率推到 3Hz 以上,必然振**。
- * 故取 8:低于自激斜率,把穿越频率压到约 1.3Hz。
- *
- * 大 → 收敛快、残差小,但越过 ~11 就开始 3Hz 自激;
- * 小 → 滞后大,靠前馈补跟踪,稳态残差变大。
- * 依据:旧律平方段在 3.7° 处斜率 3×1.5×3.7 ≈ 11,该点实测自激 → 取 8 留 27% 裕度。
- * 调参顺序:只改本宏,6 → 8 → 10 各跑一次匀速推杆,看 3Hz 分量与稳态 |off|(基线 5.4°)。
- * 回退:出现 3Hz 抖动回 6;稳态 |off| 明显变大则先查前馈,不要加增益。


## CHASSIS_FOLLOW_DEADBAND

- * 故低于死区时位置项清零,超出后先减死区再进律,保证边界处输出连续无跳变。
- * 大 → 云台与底盘允许更大夹角,小角度不跟随;
- * 小 → 残差区间内持续输出,底盘在静止时轻微抖动。
- * 依据:2.0 = 旧结构残差上限 1.4 + 0.6 余量。加装云台/自瞄后实测残差上限升到 2.33,
- * 2.0 落进残差带内 → 静止时有 2~3°/s 的空指令(被四轮静摩擦吃掉)。
- * 2026-11-16 试过改到 3.0,**回中抖动依旧**(抖动来自 spd/ff 两项,它们绕过死区),
- * 故退回 2.0 保持原手感;该空指令暂不构成可观测问题,留待真正消除抖动后再定。


## CHASSIS_FOLLOW_TARGET_OFFSET

- * 0 = 车头正对云台方向(常规跟随)。设成非 0 即"侧身跟随/扭腰",例如 ±90 让底盘侧对目标。
- * 对应官方 Development-Board-C 的 `chassis_relative_angle_set` 与上交的 `twistGapAngle`;
- * 官方实现里这本来就是 PID 的 setpoint 而非硬编码 0,我们此前写死了。
- * 注意:改本值会让底盘在跟随态保持一个固定夹角,回中(CHASSIS_ALIGN)仍以 0 为目标,两者不一致属预期。


## CHASSIS_FOLLOW_FF_SLEW

- * 只限制"前馈从小变大"的速率;前馈到顶后不再受限,位置项也完全不受本项约束
- * (上一版限制的是总指令,把位置项也压住了,才拖累中间段)。
- * 下落不限:松杆时前馈立刻归零,不拖慢撤力。
- * 云台自己起步约 1600 °/s²(0→245 用 0.15s),本值 400 = 比云台慢 4 倍爬。
- * 大 → 起步更接近云台;小 → 更软;0 = 关闭。


## CHASSIS_FOLLOW_FF

- * 结构含义:云台转多快、底盘就转多快。系数 1.0 是零滞后跟踪的唯一取值——
- * 低于 1 时剩余份额永远由位置环补,稳态落后 (1−FF)×gz/KP。
- * 11-18 曾试过 1.0 并随后整段回退,当时的原因不是 1.0 本身,而是
- * **前馈与位置项先加后削**:0.9×gz 单项就能顶穿 300 上限。现在改为额度分配(见 chassis.c),
- * 前馈先占额度但给位置项强制保留 CHASSIS_FOLLOW_P_RESERVE,不再互顶。
- * 符号:推杆后偏得更厉害(发散)就把本宏改成负值,不要动别处。


## CHASSIS_FOLLOW_BRAKE_ON_RATE

- * 调小(5)  → 等手真的松干净才刹,介入晚、更自然
- * 调大(30) → 手还没完全松开就介入,介入早、更果断
- * 目标角速度经一阶低通(robot_cmd.c 里 0.35),从满杆降到低于本值约 20~40 ms。
- * "刹得太早"优先调它,不要先动 BRAKE_ANT。


## CHASSIS_FOLLOW_BRAKE_ANT

- * 判据:操作手已松手(yaw_rate_cmd≈0)但云台还在转(gz>30)、底盘还在跑(est>40)。
- * 触发时输出 -本值×est,直接按底盘速度反着刹 —— 比 AFF 早约 0.1 s 开始。
- * 为什么需要:实测松杆后底盘还要走 3~5°(100°/s 时),这 0.08 s 里 AFF 还等着 α 变化,
- * 而目标角速度已经归零 —— 那 0.1 s 就是可以榨出来的制动距离。
- * 0.5 温和,0.8 接近"立刻停",1.0 以上会反向冲。
- * 前提:cmd 层已把 gimbal_cmd_send.yaw 的微分发布到 chassis_cmd_recv.yaw_rate_cmd。


## CHASSIS_FOLLOW_KD

- * 归零原因(实车体感 + 机理):本项 = KD×(gz−est),是速度误差放大器。
- * 起步时 est 落后 gz,它给正值把底盘额外推快 → 底盘冲过云台 → 整个转向段带稳态误差、
- * 结束时再回摆。而 FF=1.0 已经把"该转多快"给足了,不需要再叠速度误差。
- * 刹车的职责已交给 CHASSIS_FOLLOW_AFF(只作用于减速段)。
- * 若某天要重新用它:只在松杆刹车不足、且 AFF 已加到 0.2 仍不够时才开,从 0.2 起。
- * 输入不是 offset 的差分(那要 3Hz 低通,滞后十几 ms,在 200Hz 环里是负资产),
- * 而是实测相对速率 (gz − est_wz):云台世界角速度 减 底盘逆解角速度。
- * 用途:若 KP 提到 10 以上出现 3Hz 自激,**先别降 KP**,试本项 0.1~0.3 ——
- * 速度反馈是带惯量的底盘唯一干净的阻尼来源。
- * 风险:est_wz 来自轮速逆解,打滑时失真;本项会把打滑误判成"底盘转太快"而反向修正。
- * 调法:0.1 → 0.2 → 0.3,每次只加一档,看 3Hz 分量是否下降且稳态 |off| 不增大。


## CHASSIS_FOLLOW_P_RESERVE

- * 前馈先占额度,但最多占 (1−本值),保证云台极速转动时位置项仍有 25%×300 = 75°/s 的修正力。
- * 大 → 前馈让位多,跟踪略滞后,但不会"追不上就再也追不上";
- * 小 → 前馈几乎独占,云台快转时位置项被饿死。
- * 0.25 是按实测缺口定的:云台满杆 Gyro[2] 可到 400+°/s,而底盘自转上限 300°/s。


## CHASSIS_FOLLOW_AFF

- * 律:wz += AFF × d(gz)/dt,即用云台角加速度补底盘惯量(伺服三环里的 AFF,
- * Fanuc No.1826 / 西门子 MD32820;VFF 是现在那个 FF×gz,只管匀速段)。
- * **为什么需要它**:松杆瞬间 gz 从 200+°/s 掉到 0,α ≈ −2000 °/s²,靠位置项等误差攒出来
- * 才刹车 → 实测溜车 20°、off 摆幅 17°。AFF 用加速度直接给出反向力矩,不用等误差。
- * **为什么它不会像 KP 那样把 3.5Hz 抖动带回来**:匀速时 α=0 → AFF 恒为零;
- * 且前馈在开环通道上,不改变闭环极点(不影响稳定裕度)。
- * 同源实现:本工程 yaw 轴的 YAW_INERTIA_FF_GAIN(τ=J·α,DEV-20261117-12)。
- * 标定:先 0.05 → 0.1 → 0.15,看溜车/摆幅是否下降且匀速段无高频抖。
- * 典型量级:α 峰值约 2000 °/s²,系数 0.1 → 贡献 200 °/s,正好抵一个满速刹车。
- * 过大:相位超前过量 → 停杆时反向冲过头(和 KD 过大同一类症状)。


## CHASSIS_FOLLOW_AFF_LP

- * gz 差分噪声大(16ms 间隔下 1°/s 抖动 → 62 °/s² 假加速度),必须滤。
- * 大 → 响应快但噪声直通;小 → 平滑但滞后,失去"提前刹车"的意义。


## CHASSIS_FOLLOW_NO_OVERSHOOT

- * 输出推到 |gz| 之外。**专门解决"起步底盘速度超过云台"**。
- * 只在前馈上升段(α·gz ≥ 0,即云台还在加速或匀速)生效;减速段不复用,
- * 否则松杆时 gz 已掉到几十而 est 还高,这条会把刹车指令一起砍掉。
- * 未追平时(|est| < |gz|)不限制 —— 否则底盘永远补不上差距。
- * 关掉(0)即恢复"各项自由叠加"。


## CHASSIS_FOLLOW_AFF_GATE

- * 起因:无门控时静止会持续抖动 —— gz 静止噪声约 ±1°/s,16ms 差分放大成 ±60°/s² 假加速度,
- * 乘 AFF=0.10 得 ±6°/s 的假指令,在 2° 死区边上反复顶位置项。
- * 取 max(|gz|, |est_wz|) > 本值才生效:打杆时两者都是 100~200,松杆后也还有几十,
- * 而静止时都在 ±3 以内,一刀切开。


## CHASSIS_FOLLOW_AFF_ACCEL_ON

- * 起因:两个方向用同一个系数时,起步段 AFF 叠在 FF 上把底盘推过云台
- * (用户体感"转向时底盘超过了云台,结束后又回转"),而减速段正是缺刹车的地方。
- * 需求本来就不对称:加速段 FF+P 已把底盘推到极限,再补只会冲过头;
- * 减速段没有任何环节负责,只能靠位置误差慢慢拉。
- * 改 1 恢复对称(仅在相位超前过量可接受时用)。


## CHASSIS_FOLLOW_AFF_RATE_MIN
