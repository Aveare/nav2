# Sentry NUC—STM32 USB 虚拟串口通信协议

本文定义 NUC 与 STM32F407 哨兵电控共用一根 USB CDC 虚拟串口时的线上协议。字节流同时承载 `NV v1` 导航帧和 RMCV 自瞄帧，当前只允许以下六类消息。

| 方向 | 协议 | 消息 | 长度 | 计划频率 | 当前处理 |
| --- | --- | --- | ---: | ---: | --- |
| NUC → STM32 | NV v1 | `COMMAND=1` | 32 B | 50 Hz | 解析速度；默认不接管底盘 |
| STM32 → NUC | NV v1 | `FEEDBACK=2` | 32 B | ≤50 Hz | 上报大 yaw 相对角和 CAN 样本时间 |
| NUC → STM32 | NV v1 | `SYNC_REQUEST=3` | 32 B | 2 Hz | 请求 MCU—ROS 软件测时 |
| STM32 → NUC | NV v1 | `SYNC_RESPONSE=4` | 32 B | 请求触发 | 回显序号并写 MCU 处理时间 |
| STM32 → NUC | RMCV | `0x1021` | 31 B | ≤100 Hz | 上报大 yaw 平台 IMU 姿态 |
| NUC → STM32 | RMCV | `0x0503` | 39 B | 100 Hz | 校验后进入自瞄(云台/连发);热量守卫是发射最终闸门 |

`0x1022` 和裁判状态 `0x1023～0x1026` 均为未实现草案，不属于线上协议。裁判系统仍通过 USART6 进入 STM32，没有全量转发到 USB。

## 当前安全状态

- STM32 `SENTRY_AUTONOMY_ENABLE=1`：解析命令、回复测时并回传大 yaw；只有左右拨杆中位 + 左右摇杆回中 + 命令有效时才接管底盘，摇杆动作立即回手动。
- NUC 的 `sentry_usb_bridge` 默认 `enable_drive=false`，只发送无效零速帧。
- STM32 解析 `0x0503` 并维持 100 ms 新鲜度；左中挡/键鼠 Shift 自瞄时目标进入云台，`shoot` 经热量守卫请求连发。
- `0x1021` 发送大 yaw 平台 IMU 姿态；弹速、模式和本车 ID 由裁判数据运行期刷新（`vision_link_set_*`），默认占位 `0`。
- 两端开关必须同时启用，且遥控器左右拨杆均在中位、右摇杆回中，导航才可能接管底盘。
- 代码、主机测试和 ARM 编译不能替代烧录、实体 USB、云台、发射或底盘闭环验收。

## 物理链路与分流

- 物理设备为 STM32 USB FS CDC ACM；现场优先使用 `/dev/serial/by-id/...`，不要依赖会变化的 `/dev/ttyACM0`。
- NUC 只能有一个进程打开该设备；旧串口节点不得与统一桥接节点并行。
- STM32 USB 回调每块最多 64 B，只复制数据和接收时刻，200 Hz `autonomy_task()` 执行解析。
- USB 数据块边界不等于协议帧边界。两个流式解析器都支持分包、粘包和错误后重同步。

| 字节前缀 | 解析器 |
| --- | --- |
| `4E 56 01`，即 `NV\x01` | NV v1 固定 32 B 解析器 |
| `A5` | RMCV 变长帧解析器 |
| 其他 | 逐字节滑动，继续寻找下一帧头 |

多字节整数和 IEEE754 binary32 均使用小端。禁止直接发送 C 结构体内存。NaN、Inf、CRC 错误、长度错误以及字段越界均不得刷新命令有效期。

## ROS 2 接口

NUC 端唯一串口所有者是 `cod_nuc_bringup/sentry_usb_bridge.py`。不要同时运行旧串口节点或第二个进程打开相同设备。

| 方向 | 话题 | 消息类型 | 约束 |
| --- | --- | --- | --- |
| ROS → bridge | `/cmd_vel` | `geometry_msgs/msg/Twist` | 使用 `base_link` 语义；`linear.x` 前进、`linear.y` 左移、`angular.z` 逆时针 |
| ROS → bridge | `/Odometry` | `nav_msgs/msg/Odometry` | `header.frame_id=odom`、`child_frame_id=base_link`；只用于新鲜度门控 |
| bridge → ROS | `/big_yaw/joint_states` | `sensor_msgs/msg/JointState` | `name=["big_yaw_joint"]`，`position[0]` 为相对底盘角，单位 rad |
| bridge → ROS | `/autoaim/pose` | `rm_interfaces/msg/AutoAimPose` | 来源为 `0x1021`；姿态仅代表大 yaw 平台 IMU |
| ROS → bridge | `/autoaim/target` | `rm_interfaces/msg/AutoAimTarget` | 编码成 `0x0503`；当前 STM32 仅缓存 |

桥接节点以 200 Hz 轮询串口、每 20 ms 发送一次速度帧、每 500 ms 发一次测时请求。只有以下条件全部满足才设置速度帧 `VALID`：

1. `enable_drive=true`。
2. `/cmd_vel`、`/Odometry`、大 yaw 反馈的年龄均不超过 0.2 s。
3. Odometry 消息时间戳年龄位于 -0.02~0.2 s。
4. 最近 2 s 内获得有效 MCU 时钟同步。
5. 每轴平移速度不超过 0.35 m/s，角速度不超过 0.5 rad/s，且全部为有限数。

任一条件失效时，NUC 连续发送无效零速帧；STM32 另有 300 ms 接收超时兜底。

## NV v1 帧

所有多字节字段均为小端。帧固定 32 字节，不直接传输 C 结构体。

| 偏移 | 长度 | 字段 |
| ---: | ---: | --- |
| 0 | 2 | ASCII `NV` |
| 2 | 1 | 版本 `1` |
| 3 | 1 | 消息类型 |
| 4 | 4 | `uint32` 序号 |
| 8 | 8 | `uint64 sample_us` |
| 16 | 12 | 3 个 IEEE754 binary32 |
| 28 | 2 | `uint16 flags`，bit0=`VALID`，其余必须为 0 |
| 30 | 2 | CRC16/MODBUS，覆盖字节 0~29 |

CRC 初值为 `0xFFFF`，多项式为 `0xA001`，低字节先传；标准向量 `123456789` 的结果为 `0x4B37`。

| 类型 | 值 | `sample_us` | `float[0..2]` |
| --- | ---: | --- | --- |
| COMMAND | 1 | NUC ROS 发送时间 | `vx` m/s、`vy` m/s、`wz` rad/s |
| FEEDBACK | 2 | 大 yaw CAN 帧进入 MCU 的 tick 时间 | 大 yaw 相对角 rad、0、0 |
| SYNC_REQUEST | 3 | NUC ROS 发送时间 | 0、0、0 |
| SYNC_RESPONSE | 4 | MCU 处理时的 tick 时间 | 0、0、0 |

STM32 流式解析 USB 分包和粘包；CRC 或帧头错误时逐字节滑动重同步。有效会话只接受前进序号，重复或倒退序号不刷新超时。

## RMCV 自瞄帧

### 通用布局

RMCV 帧总长度为 `payload_length + 9`。命令号不计入 payload 长度。

| 偏移 | 长度 | 字段 |
| ---: | ---: | --- |
| 0 | 1 | 帧头 `0xA5` |
| 1 | 2 | `uint16 payload_length` |
| 3 | 1 | `uint8 sequence`，255 后回绕 |
| 4 | 1 | CRC8，覆盖字节 0～3 |
| 5 | 2 | `uint16 command_id` |
| 7 | N | payload |
| 7+N | 2 | CRC16，覆盖此前全部字节 |

| 校验 | 初值 | 反射多项式 | 最终异或 | 存放顺序 |
| --- | --- | --- | --- | --- |
| CRC8 | `0xFF` | `0x8C` | 无 | 单字节 |
| CRC16 | `0xFFFF` | `0x8408` | 无 | 低字节在前 |

### `0x1021`：STM32 姿态上行

payload 为 22 B，整帧 31 B。

| payload 偏移 | 长度 | 类型 | 字段 | 当前语义 |
| ---: | ---: | --- | --- | --- |
| 0 | 4 | `float` | `yaw` | deg，ZXY 欧拉角中的 Z |
| 4 | 4 | `float` | `pitch` | deg，ZXY 欧拉角中的 X |
| 8 | 4 | `float` | `roll` | deg，ZXY 欧拉角中的 Y |
| 12 | 4 | `float` | `projectile_speed` | m/s；当前配置值 0 |
| 16 | 1 | `uint8` | `program_mode` | 当前配置值 0 |
| 17 | 4 | `uint32` | `sample_time_ms` | 发现新 EKF 样本时的 MCU 读取时刻 |
| 21 | 1 | `uint8` | `robot_id` | 当前配置值 0 |

四元数输入为 `[w,x,y,z]`，表示机体到导航系的主动旋转，欧拉角满足 `R=Rz(yaw)Rx(pitch)Ry(roll)`。接近 ZXY 的 `pitch=±90°` 奇异点时不发送。

`sample_time_ms` 不是 IMU 硬件时间，也不是 EKF 函数内部的精确更新时间。当前 200 Hz 应用任务检测到新的 `UpdateCount` 后，以当次 `kernel_tick_ms()` 标记，通常比 EKF 更新晚不超过一个应用周期。没有新 EKF 样本时不重复包装旧姿态；USB 忙时发送顺延。

BMI088 位于大 yaw 平台，因此该帧不含小 yaw 编码器和 pitch 编码器，不能当作完整枪管或相机姿态。

### `0x0503`：NUC 自瞄目标下行

payload 为 30 B，整帧 39 B。

| payload 偏移 | 长度 | 类型 | 字段 | 单位与约束 |
| ---: | ---: | --- | --- | --- |
| 0 | 4 | `float` | `yaw` | deg，世界系绝对目标角 |
| 4 | 4 | `float` | `pitch` | deg，当前 IMU 反馈域绝对目标角 |
| 8 | 4 | `float` | `yaw_speed` | rad/s |
| 12 | 4 | `float` | `pitch_speed` | rad/s |
| 16 | 4 | `float` | `yaw_acc` | rad/s² |
| 20 | 4 | `float` | `pitch_acc` | rad/s² |
| 24 | 4 | `float` | `distance` | m，必须非负 |
| 28 | 1 | `uint8` | `shoot` | 允许值 0～3 |
| 29 | 1 | `uint8` | `target_id` | 允许值 0～9；0 表示无目标 |

所有浮点必须有限。通过 CRC、长度和字段检查后，STM32 保存命令、完成该帧的 USB 数据块接收时刻与累计计数；超过 100 ms 后 `valid=0`。当前不使用 8 位序号去重，也没有目标生成时间、图像时间或预期执行时间字段。

当前调用链止于 `vision_link_get_state()` 可读快照。没有代码把 `yaw/pitch/shoot` 接入 `gimbal_cmd` 或 `shoot_cmd`，所以“串口能收”不代表“自瞄已闭环”。

## 频率、超时和安全门控

| 项目 | 配置值 | 失效行为 |
| --- | ---: | --- |
| 应用任务 | 200 Hz | 决定 USB 软件解析与姿态读取粒度 |
| NV COMMAND | 50 Hz | STM32 300 ms 后清 `valid` |
| NV FEEDBACK | ≤50 Hz | 无新 CAN 样本不重复发送 |
| SYNC_REQUEST | 2 Hz | 由 NUC 发起 |
| RMCV `0x1021` | ≤100 Hz | 无新 EKF 样本或 USB 忙时顺延 |
| RMCV `0x0503` | 100 Hz | STM32 100 ms 后清 `valid`，当前无控制消费者 |

NV 与 RMCV 共用一个 USB TX 端口，不承诺两类上行帧同时满足理论峰值。现场应统计实际帧率、TX busy 和重连次数。

## 坐标与单位转换

ROS 使用 REP-103 的 `base_link`：

- `+x` 向前。
- `+y` 向左。
- `+z` 逆时针。

电控底盘内部使用 `x` 前、`y` 右、`wz` 逆时针，因此接收命令时执行：

```text
vx_mm_s  =  vx_m_s × 1000
vy_mm_s  = -vy_m_s × 1000
wz_deg_s =  wz_rad_s × 180 / π
```

`CHASSIS_NAVIGATION` 直接表示底盘物理坐标系，不再按大 yaw 偏角旋转速度。导航模式使用独立的 350 mm/s² 平移斜坡。

## RMCV 视觉帧（与 NV 共用同一 USB 字节流）

两协议由 `autonomy` 同一段 RX 字节分别喂入独立解析器，互不影响；`0x1021` 与 NV FEEDBACK 各自独立发送缓冲，USB 忙则顺延。

### `0x1021` 姿态上行（31 B，≤100 Hz）

| payload 偏移 | 类型 | 字段 | 说明 |
| ---: | --- | --- | --- |
| 0/4/8 | float | `yaw/pitch/roll` | deg，ZXY 欧拉角 |
| 12 | float | `projectile_speed` | m/s，取裁判 `0x0207`，没有则 0 |
| 16 | uint8 | `program_mode` | 自瞄激活=1 |
| 17 | uint32 | `sample_time_ms` | INS `UpdateCount` 变化后的 MCU tick |
| 21 | uint8 | `robot_id` | 裁判 `0x0201`，没有则 0 |

**重要**：`SENTRY_IMU_AFTER_SMALL_YAW=0`，IMU 装在大 yaw 平台；`0x1021` 只表示大 yaw 平台姿态，**不是完整枪管/相机姿态**。完整枪管姿态需要后续 `0x1022` 或 NUC 用关节角合成。

### `0x0503` 目标下行（39 B）

| payload 偏移 | 类型 | 字段 | 说明 |
| ---: | --- | --- | --- |
| 0 | float | `yaw` | deg，世界系绝对目标角 |
| 4 | float | `pitch` | deg，世界枪管 pitch 目标 |
| 8/12 | float | `yaw_speed/pitch_speed` | rad/s |
| 16/20 | float | `yaw_acc/pitch_acc` | rad/s² |
| 24 | float | `distance` | m，必须非负 |
| 28 | uint8 | `shoot` | 0=不开火，非 0=请求连发 |
| 29 | uint8 | `target_id` | 0=无目标，1~9=目标编号 |

STM32 侧行为：

1. `target_id=0`、CRC 错、非有限值、`distance<0` 或超过 100 ms 均视为无效；断帧保持 300 ms 后回手动。
2. `yaw` 经 KF + 二阶平滑后作为大 yaw 世界目标；大 yaw 承担快速世界环，小 yaw 只做慢配平（`SENTRY_AUTO_AIM_SMALL_TRIM_LP`）。
3. `pitch` 按 `SENTRY_PITCH_ZERO_RAD + (世界目标 − 平台 Pitch)` 映射到 pitch 关节；首次进入以实测角为种子。
4. `shoot!=0` 且目标有效时发 `LOADER_BURST` + 摩擦轮 ON，射速按战术档位；热量/额度守卫仍是唯一放行点。
5. 自瞄与右下滑小陀螺可同时使用；大 yaw 的世界速度反馈会抵消底盘转速。

**世界系合同**：`0x0503.yaw` 必须与 `0x1021.yaw` 处于同一世界系。若 NUC 使用 ROS odom/map 而 STM32 使用上电 EKF 零位，需 NUC 侧换算，或用 `SENTRY_AUTO_AIM_YAW_OFFSET_DEG` 标一个固定偏置。`pitch` 目前按“世界枪管 pitch”实现，NUC 若给的是平台相对 pitch 需先改语义。

## 启动与检查

NUC 当前服务名为 `cod-sentry-usb-bridge.service`，串口应使用稳定的 `/dev/serial/by-id/...` 路径。

```bash
systemctl --user status cod-sentry-usb-bridge.service
ros2 node info /sentry_usb_bridge
ros2 topic hz /big_yaw/joint_states
ros2 topic echo /big_yaw/joint_states --once
```

如果烧录新固件后仍没有 `/big_yaw/joint_states`：

1. 确认 `/dev/serial/by-id/...` 存在且服务用户可访问。
2. 确认没有其他进程占用同一 VCP。
3. 检查 STM32 是否收到大 yaw DM CAN 反馈；没有新 CAN 时间戳时固件不会伪造新角度。
4. 查看服务日志中的 USB 重连、CRC、测时或串口写阻塞信息。

## 实车放行顺序

1. 保持 NUC `enable_drive=false`，先确认测时响应和 `/big_yaw/joint_states` 约 50 Hz。
2. 架空底盘，分别核对正前、左移、逆时针三个符号。
3. 断开 `/cmd_vel`、`/Odometry`、大 yaw CAN 和 USB，逐项确认零速/零力降级。
4. 导航验收通过后再以 `enable_drive=true` 启动桥接；STM32 `SENTRY_AUTONOMY_ENABLE` 已为 1，需要临时禁用时置 0 重烧。
5. 自瞄先关 `SENTRY_AUTO_AIM_FIRE_ENABLE`，只验目标跟踪；再空仓验拨盘/摩擦轮；最后实弹。
6. 首次落地限低速、留急停人员，不同时开展导航参数整定和云台/发射调试。

ROS 端实现位于 Aveare/nav2 的 `src/cod_nuc_bringup/scripts/sentry_usb_bridge.py`。STM32 的 NV 编解码位于 `components/navigation/`，RMCV 编解码位于 `components/ax650/ax650_pose.c`，USB 唯一所有者及协议状态位于 `apps/sentry/autonomy/`。
