# 哨兵功能检查表(3 小时台架版)

> 用法:按顺序打勾;任一项 **FAIL** 先停下修硬件/接线,不要继续调参。
> 时间盒:0:00–0:30 上电与链路;0:30–1:10 手动三轴;1:10–1:40 自瞄;
> 1:40–2:10 导航;2:10–2:35 发射/热量;2:35–3:00 记录与回退。
> 对应参数与判据见 `../params/待标定表.md`、`../params/待实测参数表.md`。

## A. 上电前(0:00–0:15)

- [ ] 四轮悬空/架空,云台行程内无干涉,线束不拉拽。
- [ ] 大 yaw 同步带张紧、无 5~7° 虚位(本轮按已修好处理)。
- [ ] 小 yaw 手转左右各 ≥136°,无卡死;中位 ECD 27 可复现。
- [ ] pitch 手推全行程,枪管/连杆不顶死;记住机械上下限。
- [ ] DM 大 yaw/pitch 的 CAN ID、Master ID、TMAX 与 config 一致。
- [ ] 小 yaw GM6020 拨码 ID1(CAN2);摩擦轮/拨盘 ID 与 config 一致。
- [ ] 裁判 USART6、DBUS USART3、USB CDC、USART1 VOFA 接线正确。
- [ ] 固件 `firmware/sentry.elf` 与 `PROFILE=sentry` 一致。

## B. 上电与链路(0:15–0:30)

- [ ] 上电无异常电流/异响;`ROBOT_STATUS_STOP` 下三轴零力可手推。
- [ ] RTT 有启动日志;无 `[FAULT]`/`err` 挂死。
- [ ] USART1 VOFA 三通道 200 Hz:大 yaw 多圈、小 yaw ECD、pitch 多圈。
- [ ] USB 枚举成功;NUC 能收到 `0x1021`(≈100 Hz,`sample_time_ms` 单调)。
- [ ] NUC 发 `0x0503` 无效帧(`target_id=0,shoot=0`),STM32 `command_count` 增长,100 ms 后 `valid=0`。
- [ ] 裁判 `0x0201/0x0202/0x0207/0x0208` 至少 `0x0201` 有数据;热量守卫不误锁。

**通过判据**:链路全通,无控制动作;否则不进 C。

## C. 手动三轴与底盘(0:30–1:10)

- [ ] 解锁:右上 + 左中 + 全回中 → READY;右中挡进入不跟随。
- [ ] **上电前把大 yaw 摆到车头标记**(上电校准:首个有效反馈锁定为前方参考,`sentry_big_yaw_front_align_deg` 可查)。
- [ ] 大 yaw:右中挡下不跟随;右下挡 150°/s,方向正确;手推后能回正前方(回正目标是上电时的车头)。
- [ ] 小 yaw:左下挡左横杆正/负方向正确;到 ±115° 前减速/停住,不撞机械限位。
- [ ] pitch:左纵杆上推枪口上抬;到 ±20° 限位停住;松杆无持续下滑/自激。
- [ ] 平移:右摇杆前/后/左/右方向正确;斜向合速度不超过 1500 mm/s。
- [ ] 急停:左/右上挡、拨轮 >300、拔 DBUS → 全部零力;重新解锁正常。
- [ ] 小陀螺:右下挡旋转平稳;大 yaw 世界指向保持(手转底盘时枪口不跟着转)。

**通过判据**:方向/限位/急停全对;记录大 yaw 电流/温度、pitch 稳态电流。

## D. 自瞄(1:10–1:40)

先 `SENTRY_AUTO_AIM_FIRE_ENABLE=0` 重烧。

- [ ] 左中挡进入自瞄;`program_mode=1`;松开/切左下退出。
- [ ] 静态目标 ±20°:大 yaw 快速转,小 yaw 慢配平;枪口指向目标。
- [ ] 静态目标 ±60°/±120°:小 yaw 不长期顶死;大 yaw 承担剩余。
- [ ] 世界 yaw 对齐:枪口对准已知方位,NUC 发同方位目标,大 yaw 原地不动;否则记偏置。
- [ ] pitch 静态 ±5°/±10°:方向正确,不过冲撞限位;记录稳态误差。
- [ ] 目标丢失:保持 300 ms 后回手动;重新出现能重新捕获。
- [ ] 小陀螺 + 自瞄:右下挡下目标仍稳定;大 yaw 温度不快速升到 65°C。
- [ ] 键鼠 Shift 自瞄:按住有效,松开回手动。

**通过判据**:静态目标不振荡、不撞限位、断帧可回退;记录 yaw 偏置与 pitch 误差。

## E. 导航(1:40–2:10)

- [ ] NUC `enable_drive=false` 时,STM32 只回传,不接管底盘。
- [ ] 左右拨杆中位 + 左右摇杆回中,NUC 发 0.1 m/s 前进 → 底盘按斜坡起步。
- [ ] 方向:前进/左移/逆时针分别正确;轮速方向与 `est_vx/est_vy` 一致。
- [ ] 0.35 m/s + 0.5 rad/s 组合:轮速 < 7000 rpm;无堵转/过流。
- [ ] 断 `/cmd_vel`/USB:300 ms 后按斜坡停车;0.35 m/s 约 1 s 停。
- [ ] 推动右摇杆:立即回手动,导航不再覆盖。
- [ ] 自瞄 + 导航同时:底盘按 NV 走,云台仍跟视觉目标。

**通过判据**:方向/超时/接管全对;记录停止距离与轮速峰值。

## F. 发射与热量(2:10–2:35)

先空仓,再装 1~3 发。

- [ ] 拨轮压入 → 摩擦轮启动;双轮在线且到速(4000 RPM 目标)后才允许拨弹。
- [ ] 短拨单发 1 发;按住连发;松手停;无连击/卡弹。
- [ ] 三发:逐发到位,不出现 4~5 连;堵转 500 ms 锁存,拨轮回中解除。
- [ ] 热量:裁判在线时 `heat_state` 随热量变化;HOLD 时拒发;断裁判台架直通。
- [ ] 视觉 fire(重新打开 `FIRE_ENABLE=1`):`shoot=1` 才连发;目标丢失停火。
- [ ] 记录实际弹速(裁判 0x0207)与摩擦轮 RPM;若目标 24 m/s 不足,先调 `SHOOT_FRICTION_TARGET_RPM`。

**通过判据**:单发/连发/热量/堵转全对;记录摩擦轮 RPM-弹速关系。

## G. 收尾(2:35–3:00)

- [ ] 记录所有改动宏、旧值/新值、现象、通过/失败。
- [ ] 失败项写回 `../params/待实测参数表.md` 的风险列。
- [ ] 固件/参数回退点:`git` 提交 + `firmware/sentry.elf` 备份。
- [ ] 清理台架,恢复 `SENTRY_AUTO_AIM_FIRE_ENABLE` 等安全默认。

## H. 红线(出现即停)

- DM 状态 `0xB`(MOS 过温)/`0xC`(绕组过温)/`0xE`(过载)反复出现;转子/MOS 温度 ≥65°C。
- GM6020 橙灯 1 Hz(>100°C)、红灯 4 Hz(>125°C)或橙灯常亮(电流模式收到电压指令)。
- **不要把 8 字节全 0 当零力矩**:DM MIT 的 `raw=0` 是 `-TMAX`;本工程驱动已把 0 N·m 映射到中值,不要手发裸 0 帧。
- DM 反馈 >100 ms 不报错/不失能;编码器跳变/零点漂移;同步带死区 >0.3°。

- 大 yaw DM 状态 `0xC`/温度 ≥65°C;电机异响/过热。
- 小 yaw 撞机械限位或持续单向顶死。
- pitch 撞限位/枪管下坠/自激振荡。
- 底盘轮速顶 7000 rpm 或电流持续饱和。
- 任何零力/急停失效、DBUS 失联不锁存。
