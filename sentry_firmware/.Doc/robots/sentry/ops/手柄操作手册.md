# 哨兵手柄操作手册

> 适用固件:`feat/sentry/autoaim-nav-power-youyucat` 及后续合并版。
> 参数入口:`config/sentry_2026/`;本文只写操作与现象,数值以 config 为准。
> **上电默认全部零力;必须走解锁流程才会动。**

## 1. 上电与解锁

1. 遥控器开机,确认 C 板 DBUS 在线(USART3)。
2. 车上电;`ROBOT_STATUS_STOP` = 零力,云台可手推。
3. 解锁组合:**右上挡 + 左中挡 + 全部摇杆/拨轮回中**。
   - 右上挡期间仍为零力;把右拨杆拨到**中挡**才进入正常控制。
   - 解锁只重锚定云台目标,不触发底盘自动回中。
4. 急停:左/右上挡任一向上,或拨轮 > 300,或遥控失联 → 立即零力并锁存;重新解锁需再走第 3 步。

## 2. 模式表

| 左拨杆 | 右拨杆 | 底盘 | 云台/小 yaw |
|---|---|---|---|
| 上 | 任意 | 急停 | 零力 |
| 中 | 中 | `CHASSIS_NO_FOLLOW`(不跟随) | **自瞄**(左中挡) |
| 中 | 下 | `CHASSIS_ROTATE` 小陀螺 150°/s | **自瞄 + 小陀螺**(大 yaw 世界环自行补偿) |
| 下 | 中 | 不跟随;左横杆控小 yaw | 手动:左横杆小 yaw 速率 |
| 下 | 下 | 小陀螺;左横杆控小 yaw | 手动 + 小陀螺 |
| 上 | — | 急停 | 零力 |

- **右中挡**:右摇杆自由平移(前后/左右),不跟随大 yaw。
- **右下挡**:底盘小陀螺 150°/s;自瞄时仍可用,大 yaw 会反向补偿保持世界指向。
- **左中挡**:自瞄;无有效视觉目标 300 ms 后自动退回手动,手动 pitch 杆仍可用。
- **左下挡**:退出自瞄;左横杆改为小 yaw 相对速率(±120°/s 满杆)。

## 3. 自瞄与视觉开火

- 激活:**左中挡**,或键鼠输入源下**按住 Shift**。
- 视觉目标来自 USB `0x0503`(100 Hz);目标丢失保持 300 ms,超时回手动。
- 自瞄时:
  - 大 yaw 追世界目标;小 yaw 只做慢配平(两轴目标之和恒等于世界目标);
  - pitch 用视觉绝对目标(世界 pitch − 平台 pitch 映射到关节);
  - 鼠标/左纵杆不再叠加云台目标(手动 pitch 杆在自瞄有效时被屏蔽)。
- 视觉开火:自瞄有效且 `0x0503.shoot != 0` → 摩擦轮 ON + 按战术档位连发;热量/额度守卫仍是最终闸门。
- **首次联调先关开火**:把 `SENTRY_AUTO_AIM_FIRE_ENABLE` 置 0 重烧,只验跟踪;确认后再开。
- 战术射速档:键鼠 X 循环 ECO(3 发/s)→ NORMAL(6)→ BURST(12);遥控没有 X 键,档位由键鼠设置后保持。

## 4. 导航接管

- STM32 `SENTRY_AUTONOMY_ENABLE=1`;NUC 侧 `enable_drive=true` 才发有效速度。
- 接管条件:**左右拨杆中位 + 左右摇杆回中 + NV COMMAND 在 300 ms 内有效**。
- 任一右摇杆动作 → 立即回手动;拨杆离开中位 → 导航退出。
- 导航模式使用独立 350 mm/s² 斜坡;命令超时/断 USB 后按斜坡停车(0.35 m/s 约 1 s)。
- 自瞄与导航可同时:左中挡自瞄 + 右中挡导航;底盘按 NV 速度走,云台按视觉目标稳。
- **自瞄 + 小陀螺**只在右下挡;导航要求右中挡,两者不叠加。

## 5. 发射(遥控拨轮)

| 操作 | 效果 |
|---|---|
| 拨轮压入 ≤ −240 | 进入扳机区:摩擦轮 ON |
| 短拨松手(<250 ms) | 登记 1 发 |
| 按住 ≥250 ms | 连发至松手 |
| 拨轮回到 > −220 | 退出扳机区,摩擦轮延时 1 s 关 |
| 拨轮 > 300 | 急停锁存 |

- 单发/三发只在枪口热量允许、摩擦轮双轮在线且到速时才会起步;堵转 500 ms 锁存,拨轮回中解除。
- 视觉 fire 与拨轮共用同一套热量/互锁,视觉不会绕过裁判额度。

## 6. 键鼠

| 操作 | 效果 |
|---|---|
| W/A/S/D | 底盘平移;斜向自动归一化 |
| Shift 按住 | 自瞄;松开回手动 |
| 鼠标移动 | 手动云台(1:1);自瞄时由视觉给目标 |
| 右键 / 左键 | 摩擦轮 / 连发 |
| R / E | 单发 ×1 / 三发 ×3 |
| Q | 小陀螺切换 |
| X | 战术射速档 |
| V / B / G | 灵敏度降 / 升 / 复位 |
| F | 回正(当前 `SENTRY_GIMBAL_RECENTER_ENABLE=0`,无效) |

- 键鼠任一动作激活键鼠源;3 s 无输入回落遥控(小陀螺锁存期间不回落)。

## 7. 异常与急停

| 现象 | 处理 |
|---|---|
| 云台/底盘突然零力 | 看 RTT:`authority: RC lost / kill switch / dial stop`;检查拨杆、拨轮、DBUS |
| 自瞄不跟 | 看 `0x0503` 计数与 `command_valid`;检查 `SENTRY_AUTO_AIM_ENABLE`、左中挡、目标 `target_id != 0` |
| 大 yaw 过温撤力 | DM `T_Mos/T_Rotor` ≥ 65°C;停机冷却,检查机械阻力/同步带;重新解锁 |
| 小 yaw 顶住一边 | 看 `sentry_small_yaw_limited`;是否超过 115° 控制限位或机械 ±136° |
| 导航不动 | 检查两拨杆中位、左右摇杆回中、NV COMMAND 有效、USB 同步;NUC `enable_drive` |
| 视觉开火不响应 | 先看热量状态/额度;再看 `shoot` 字段与目标有效性;`SENTRY_AUTO_AIM_FIRE_ENABLE` |

## 8. 运行期可写参数(不重烧)

以下符号在 ELF/DWARF 中可直接用调试器/EmberProbe 写,默认值等于 config,掉电恢复:

| 符号 | 默认 | 安全范围 | 用途 |
|---|---:|---|---|
| `sentry_rt_big_yaw_angle_kp` | 20 | 8~20 | 大 yaw 角度环 Kp;抖动先降 12/8 |
| `sentry_rt_big_yaw_speed_kp` | 4.2 | 3~6 | 大 yaw 速度环 Kp |
| `sentry_rt_big_yaw_speed_ki` | 0.8 | 0.5~1.5 | 大 yaw 速度环 Ki |
| `sentry_rt_big_yaw_torque_limit_nm` | 10 | 3.5~10 | 大 yaw 力矩上限;DM 连续 3.5/峰值 12.5,过温先 7 |
| `sentry_rt_small_yaw_max_out` | 16000 | 8000~16000 | 小 yaw 电压帧输出上限;GM6020 连续 1.2 N·m |
| `sentry_rt_small_yaw_limit_deg` | 125 | 90~130 | 小 yaw 控制限位;机械 ±136 |
| `sentry_rt_pitch_zero_rad` | -1.935 | 仅重标后改 | pitch 水平零位;写错会撞限位 |
| `sentry_rt_pitch_gravity_a/b/phase` | 0/0/0 | A 0~0.8,B −0.2~0.2 | 重力前馈;先按待标定表拟合 |
| `sentry_rt_auto_aim_yaw_offset_deg` | 0 | −180~180 | 世界 yaw 固定偏置 |
| `sentry_rt_friction_target_rpm` | 4000 | 3000~8000 | 摩擦轮目标 RPM(互锁/遥测同源) |
| `sentry_rt_nav_accel_mm_s2` | 350 | 350~1500 | 导航斜坡/停止距离 |

写入后下一个 5 ms 控制周期生效;改坏了立即写回默认。增益类变量不建议在车高速运动时大改。

## 9. 现场调试入口

- 参数全部在 `config/sentry_2026/`;改完必须 `build.ps1 sentry -Current` 重烧。
- 自瞄:`SENTRY_AUTO_AIM_*`;导航:`SENTRY_NAVIGATION_*`;功率:`CHASSIS_POWER_*`。
- 详细标定顺序见同目录 `功能检查表.md` 与 `../params/待标定表.md`。
