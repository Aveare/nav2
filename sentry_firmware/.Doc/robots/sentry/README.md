## 链路与操作（迁移自 2026-11-26 根 README）

- **USART1 = 云台三轴编码器 VOFA**：921600 8N1，PA9 TX / PB7 RX；VOFA+ 选 JustFloat，
  200 Hz 发送 3 个 float（大 yaw 多圈角 / 小 yaw ECD / pitch 多圈角）+ `00 00 80 7F`。
- **USB CDC = 唯一上位机链路**：NV v1 导航（`COMMAND/FEEDBACK/SYNC`，32 B）+
  RMCV 视觉（`0x1021` 姿态上行 / `0x0503` 目标下行）；`autonomy` 是唯一所有者，两协议共享字节流、各自按帧头重同步。
- **USART6 = 裁判系统**（115200 8N1）。AX650 USART1 已停用（`AX650_UART1_ENABLE=0`）。

### 遥控器

| 操作 | 效果 |
|---|---|
| 左/右上挡 | 急停 + 锁存 |
| 右上 + 左中 + 全杆回中 | 解锁；只重锚云台目标，不触发底盘自动回中 |
| 右中挡 | 底盘不跟随大 yaw；右摇杆自由平移；自瞄时可继续用 |
| 右下挡 | 小陀螺（ROTATE）；**自瞄时仍允许**，大 yaw 世界环自行补偿底盘转速 |
| 左中挡 | **自瞄**：大 yaw 世界目标 + pitch 绝对目标 + 小 yaw 慢配平；无目标 300 ms 回手动 |
| 左下挡 | 退出自瞄；左横杆控小 yaw 速率 |
| 左摇杆纵向 | pitch |
| 拨轮下压 | 启动摩擦轮；短拨=单发，按住≥250 ms=连发；2.5 s 后自动关摩擦轮 |
| 拨轮 > 300 | 急停锁存 |

### 键鼠（任意键鼠动作激活，3 s 无输入回落遥控）

| 操作 | 效果 |
|---|---|
| W/A/S/D | 底盘平移（斜向自动归一化） |
| Shift 按住 | **自瞄**（键鼠输入源）；松开回手动 |
| 鼠标移动 | 手动模式云台（线性 1:1）；自瞄时由视觉给目标 |
| 右键按住 / 左键按住 | 摩擦轮 / 连发；自瞄时左键也可请求连发 |
| R / E | 单发 ×1 / 三发 ×3 |
| Q | 小陀螺切换 |
| X | 战术射速档循环 ECO→NORMAL→BURST |
| F | yaw 回正（当前 `SENTRY_GIMBAL_RECENTER_ENABLE=0` 关闭） |
| V / B / G | 鼠标灵敏度降档 / 升档 / 复位 |
