# 利用 Ozone 进行 PID 参数整定

Ozone 的实时变量可视化(示波器)功能可以观察控制器在时域的表现:上升时间、超调量、稳态时间等。
本工程已接入遥测环形缓冲(`telemetry_yaw/pitch/chassis_cmd`),Ozone live watch 直接观测数组即可示波;
改 ref 值即可触发阶跃输入。

## 整定顺序:先内环后外环

若有已知外部扰动(阻力/重力),可在**保持 Kp 不变**时加积分,稳态时积分输出可作为**前馈**
通过 `feedforward_ptr` 送入下一级串级控制器。无模型时前馈用数据驱动法(稳态误差-参考值拟合)。

## 纯调参无模型的五步法

1. **整定 P**:二分法定大致范围。电机参考速度与实际速度放同一示波窗口;
   把 `pid_ref` 加进变量观测,改 ref 即触发阶跃。P 达到欠阻尼且只超调一个峰时,开始加 D。
2. **加 D**:务必开微分滤波(`PID_DerivativeFilter`),按闭环带宽设滤波系数。
   调 D 至 P 进入临界阻尼/过阻尼(无超调)。
3. **P、D 交替增大**直到出现不可控的微分抖动,再回调到平衡点。
4. **固定 PD,查静差**:拟合目标值-静差关系(线性/多项式/指数),拟合成前馈加入系统。
5. **加 I 消除前馈模型误差**:务必用积分分离和变速积分;参数大致即可,不求精细。

## model-based 控制

无模型控制有性能上限。建模两条路:

- **动力学推导**:分析输入(电机扭矩)与输出(速度/角度)关系得微分方程,令输入=除输出外各项,
  输出动态变为一阶线性 ODE;PID 只补偿建模误差。因素考虑越全效果越好。
- **系统辨识(频域)**:给定正弦输入序列,测相频/幅频曲线,选结构拟合(最小二乘/极大似然),
  应用超前-滞后补偿,在裕度与带宽间权衡。Ozone 可以方便地获取频率响应数据。

## 本车经验提示

- yaw 的 Kd/Kp 是**按工况调度**的(见 gimbal.c 的 UpdateYawDamping 与 Kp 调度),
  手改结构体初值会被每周期覆盖;调度参数在 `config/infantry_2026/config.h`。
- 提 Kp 时按 ζ∝Kd/√Kp 同步提 Kd,只提其一实测会失稳(历史教训)。
- 摩擦前馈 B 取**欠补偿**(60%),过补偿等效负阻尼,实测 B=18 失稳。
