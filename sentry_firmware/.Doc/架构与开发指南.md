# 架构与开发指南

## 1. 分层

```
┌─────────────────────────────────────────────┐
│ APP  application/                           │  应用状态、目标值、模式切换
│      robot.c → robot_task.c → cmd/chassis/  │  应用间只通过消息中心通信
│      gimbal/shoot                           │
├─────────────────────────────────────────────┤
│ Module modules/                             │  设备协议+闭环控制
│      dji_motor(电机) ins(姿态) remote(遥控)  │  实例化+注册回调,向上通知
│      message_center daemon telemetry ...    │
├─────────────────────────────────────────────┤
│ BSP  bsp/                                   │  片上外设服务
│      can usart spi pwm flash dwt log ...    │  实例注册制,不关心业务
├─────────────────────────────────────────────┤
│ HAL  Drivers/ + Src/Inc/ (CubeMX生成)       │  寄存器封装,USER CODE区外勿改
└─────────────────────────────────────────────┘
```

分层纪律(违者审计红旗):
1. **逻辑层禁触硬件句柄**:application/ 内不得出现 `hcan*/husart*/htim*`,一律经模块实例;
2. **单写者**:每个消息话题/共享结构体只有一个生产任务;
3. **错误上报不挂死**:库层运行期错误经返回码/日志上报进入安全态;初始化期配置错误 fail-fast(LOGERROR+挂起,此时电机未使能,本身就是安全态)。

## 1.5 相对上游框架的架构改造

本工程基于跃鹿 basic_framework(提交 1a136eb)架构开发,在其骨架上做了以下改造。
接手者先读此节再对照上游源码,避免拿原版行为误解本工程。

**框架/基础设施级改造:**

| # | 改造 | 位置 |
| --- | --- | --- |
| 1 | robot_task 拆分:头文件只含声明与启停宏,任务实现移入 .c(原版头文件含实现,多翻译单元包含会重复定义) | `application/robot_task.h/.c` |
| 2 | PID 新增 **DerivativeLimit**(D 项限幅):快速运动时截断 Dout,防"转得越快刹得越狠";两结构体字段同步 | `modules/algorithm/controller.*` |

| 4 | 遥控帧校验:帧长/开关值/通道范围非法帧清零控制量且不喂狗;在线判定需收到过有效帧 | `modules/remote/remote_control.*` |

**应用层能力(新增,已实车验证):**

- cmd:控制权仲裁 AuthorityArbitrate(失联>急停挡>拨轮/锁存>运行,统一安全态输出)、解锁回中、松杆重锚定、cmd 断流看门狗(`cmd_watchdog.h`,纯逻辑可主机单测)
- chassis:跟随律全套(软死区+小角度线性律+速度阻尼项+Gyro 角速度前馈)、平移指令斜坡
- gimbal:yaw 目标角速度前馈+惯量/摩擦前馈、Kd 按|err|调度、Kp 按相对转速调度、上电零力+解锁重锚定
- shoot:摩擦轮到速互锁、拨盘堵转锁存(松拨轮解除)
- 错误处理约定:初始化期配置错误 fail-fast 挂起;**运行期**未知模式 LOGERROR+切安全态(不挂死)

## 2. 启动与任务

启动链:`main()` → `MX_*_Init` → `RobotInit()`【关中断:BSPInit→各应用Init→OSTaskInit】→【开中断】→ `osKernelStart()`

| 任务 | 频率 | 循环体 | 栈 |
|---|---|---|---|
| INS | 1kHz | BMI088读取+四元数EKF解算 | 1024 |
| MOTOR | 1kHz | 三环PID计算+CAN组帧发送 | 256 |
| DAEMON | 100Hz | 离线检测+蜂鸣器 | 128 |
| ROBOT | 200Hz | RobotCMDTask+GimbalTask+ShootTask+ChassisTask | 1024 |
| UI | 可选(TASK_UI_ENABLE) | 裁判系统UI绘制 | 512 |

任务启停一律用 `robot_task.h` 的宏(如 `TASK_UI_ENABLE`),禁止注释启停。

## 3. 数据流

**控制流(RobotCMDTask 200Hz)**
```
遥控器(USART3回调→rc_ctrl) → RobotCMDTask
  ├─ CalcOffsetAngle()          yaw单圈角-零位=offset(±180折返)
  ├─ RemoteControlSet()         挡位→三路模式;摇杆→vx/vy/云台角目标
  ├─ 回中/仲裁                  解锁回中、失联/急停/锁存→统一安全态
  └─ PubPushMessage → [chassis_cmd] [gimbal_cmd] [shoot_cmd]
        ↓ SubGetMessage                ↓                ↓
   ChassisTask(斜坡/跟随律/    GimbalTask(双前馈/     ShootTask(互锁/
   麦轮解算/限幅→4电机)        Kd/Kp调度/双环)        堵转锁存→3电机)
```

**反馈流(中断)**
```
CAN收帧(HAL回调) → bsp_can遍历实例匹配rx_id → 模块回调
  = DecodeDJIMotor(解析+滤波+多圈计数+DaemonReload喂狗)
电机任务1kHz遍历实例算PID → sender_assignment[6]分组组帧 → CAN发送(FIFO非阻塞)
```

**消息中心**:发布/订阅,话题按名字注册,订阅者带深度1队列(保留最新)。
同一话题的所有发布者/订阅者 `data_len` 必须一致(注册时检查)。

## 4. 如何加一个新模块(以"新增某传感器"为例)

1. 在 `modules/<name>/` 建 `<name>.c/.h`,遵循实例模式:
   - `<Name>_Init_Config_s`(配置结构体) + `<Name>Instance`(实例结构体) + `<Name>Init()`(注册到BSP,返回实例指针);
   - 收数据的模块在 Init 里向 BSP 注册回调;实例里放 `DaemonInstance*` 做离线检测;
   - 头文件写清:用途、接口单位/坐标/方向、生命周期、使用限制。
2. CMake 会自动 GLOB 到新 .c;**Makefile 需手动加一行源文件**。
3. 在 application 的对应 app Init 里调用 `<Name>Init(&conf)`,保存实例指针使用。
4. 模块内不 sleep、不挂死;运行期错误 LOGERROR + 安全态。

## 5. 如何调一个新应用(如新增机构)

1. `application/<name>/` 建 `<name>.c/.h`,实现 `<Name>Init()`(注册设备)与 `<Name>Task()`(周期控制);
2. `robot.c` 的 `RobotInit/RobotTask` 按板型宏接线;
3. 若需要 cmd 下发控制:在 `robot_def.h` 加控制/反馈结构体(**注意 pack(1) 布局守卫与对端同步**)、cmd 里注册话题发布、app 里订阅;
4. 参数一律放 `config/robot_infantry_2026.h`(语义名+一行依据),不要散在业务代码里。

## 6. 构建体系

- **Makefile**(显式源列表,加新 .c 要登记)与 **CMakeLists.txt**(GLOB 自动收集)双体系;
- `-Werror`:任何 warning 都是错误;
- CubeMX 重新生成代码只覆盖 Src/Inc 的生成区,`USER CODE BEGIN/END` 之间的内容保留;
- 烧录:tasks.json 的 `download_dap`/`download_jlink`;日志:RTT(`JlinkRTTClient`)。

## 7. 调试手段

- **Ozone live watch**:`telemetry_yaw/pitch/chassis_cmd` 三个环形缓冲(256条x ref/fb/out/extra/mode),直接观测数组即可"示波";`TelemetryDump()` 整环回放;
- **RTT 日志**:LOGERROR 红色高亮;浮点需 `Float2Str()`(RTT不支持%f);
- **主机测试**:`tests/` 用 gcc 编译真实业务代码+桩接口,改逻辑先跑 `tests\run_chassis_tests.ps1`;
- **协议布局守卫**:改 robot_def.h 消息结构会触发 `_Static_assert` 编译错误,提醒同步对端。
