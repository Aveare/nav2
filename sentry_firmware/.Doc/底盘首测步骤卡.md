# 底盘首测步骤卡(装好后第一轮)

> **适用**:车装好、准备先单独验证底盘,不碰云台参数。  
> **依据**:`.Doc/底盘优化计划.md` 的 P1 + `.Doc/装机后总计划书.md` 的 S1/S2。  
> **原则**:这一轮**只测量、不改参数**。测出问题记下来,统一改,不要边测边调。**云台未装也可执行本轮**(中挡除外,见 0.5)。

## 0. 开工前必须知道的四件事

### 0.1 遥控器右开关的三个挡位(唯一的底盘模式入口)

| 右开关    | 模式                          | 底盘行为                                             | 用在哪一步     |
| ------ | --------------------------- | ------------------------------------------------ | --------- |
| **上挡** | `CHASSIS_ZERO_FORCE`        | 四轮 `DJIMotorStop`,不出力(编码器仍在读)                    | **推车测逆解** |
| **中挡** | `CHASSIS_FOLLOW_GIMBAL_YAW` | 跟随云台,静止时 `wz≈0`(死区 2° 内)                         | 平地平移      |
| **下挡** | `CHASSIS_ROTATE`            | **恒定自转** `wz = CHASSIS_ROTATE_SPEED`(**300°/s**) | 小陀螺测试     |



> 键鼠模式下只有 Q 键切 `ROTATE / FOLLOW`,**没有零力挡**——推车必须用遥控器上挡。

### 0.2 一个硬前提:云台没装好,不要用中挡

中挡的 `wz` 由三部分算成:`位置项(用 offset_angle) + 速度阻尼 + IMU 角速度前馈`。  
`offset_angle` 来自 **yaw 电机编码器 + 云台角度**。云台没装/没通电时它是垃圾值(offset ≈ 0 − YAW_ALIGN_ANGLE ≈ −156.6°),平方律直接饱和——底盘会**全速自转(顶到 300°/s 限幅),不是"缓慢"**。

**判断方法(3 分钟,放在第 3 步)**:中挡解锁、不推杆,底盘应当**完全静止**。若有持续转动 → 不要再用中挡,  
改用"路径 B"(见 §4.1),或先把 yaw 零位标好。

### 0.3 450°/s 跑不到,会被 6000RPM 削顶

按当前几何(`WHEEL_BASE=500/TW=460/RADIUS=75`,力臂等效 339.4mm)换算:

| 自转指令   | 轮子转子转速       | 是否削顶               |
| ------ | ------------ | ------------------ |
| 100°/s | 1433 RPM     | 否                  |
| 200°/s | 2866 RPM     | 否                  |
| 300°/s | **4299 RPM** | 否(余量 28%)          |
| 450°/s | 理论 6449 RPM  | **是 → 实际约 419°/s** |

**所以本轮只测 100/200/300 三档**。450 档留给后面的极限测试,而且要记**实测转速**不是名义值。  
(这也意味着 yaw 摩擦标定的 450 档拿不到 450,到时候按实测值拟合并标注。)

### 0.4 电机映射(排查时用)

| 变量            | CAN  | tx_id |
| ------------- | ---- | ----- |
| `motor_lf` 左前 | CAN1 | 4     |
| `motor_rf` 右前 | CAN1 | 1     |
| `motor_lb` 左后 | CAN1 | 2     |
| `motor_rb` 右后 | CAN1 | 3     |
| yaw(GM6020)    | CAN1 | 5     |
| pitch(M3508)   | CAN2 | 4     |
| 摩擦轮左/右     | CAN2 | 1 / 2 |
| 拨盘(M2006)    | CAN2 | 3     |

四个轮子的 `motor_reverse_flag` **统一是 `MOTOR_DIRECTION_NORMAL`**(代码只在 LF 初始化前设了一次)。  
若某个轮子装反,表现为"前进时三个正转一个反转"→ 车跑偏或原地打转,需要**单独**给那个轮子改反向,  
或直接调电机到电调的接线。

---

### 0.5 本轮专属:云台未装的三件事

**a) 上电前拔掉云台电机 CAN 线**。下挡/中挡都会 `DJIMotorEnable` 云台 yaw/pitch——
云台没装但电机线接着时,它们会真的转起来(GIMBAL_GYRO_MODE 下 yaw 有目标值),没固定的电机会甩。
**CAN 分配(以代码为准):yaw = CAN1 拨码 ID5(与底盘四轮同总线)、pitch = CAN2 ID4(与发射同总线)。**
拔掉 yaw 的 CAN1 线后,总线上仍有四个带电的底盘电调节点,ACK 正常,底盘通信不受影响;
离线的 daemon LOGERROR 刷 RTT 属预期。

**b) 中挡禁用,不要"先试试看"**。云台未装时 yaw 电机离线,
`offset_angle = 0 − YAW_ALIGN_ANGLE ≈ −156.6°` → 平方律直接饱和——
中挡一解锁底盘就**全速自转(顶到 300°/s 限幅)**,不是"缓慢自转"。§3 的可用性测试本轮预期失败,直接跳过。

**c) 重量口径:哪些数据装云台后要重测**。本轮全部空载:
- 装云台后仍有效:V1/V2 符号(运动学)、V3 的几何验收(力臂/轮径错多少,空载也一样错);
- 装云台后必须重测:V3 的偏差**数值**(打滑特性变)、启停瞬态(5.5,转动惯量大增)、温升(5.6)、
  平移斜坡冲击与 6000RPM 边界。

| 命令 | 读什么 | 用在哪 |

## 1. 架空:转向与 ID 确认(≈10 分钟)

**目的**:在车不动的前提下,确认四个轮子的安装方向、ID 映射。这一步能挡掉后面 80% 的"跑偏"。

1. 四轮**悬空**(垫起来,离地 2~3cm 即可),人不要站在车正前方;
2. 上电,开 RTT(看 `[chcal]`)/ Ozone;**确认云台电机 CAN 线已拔**(见 0.5-a);
3. 遥控右开关**下挡**(小陀螺),解锁 → 四轮开始旋转;
4. 从上往下看,记录四个轮子的旋转方向。

**判据(自转组合特征)**:四个轮子**旋转方向全部相同**。

| 现象 | 结论 |
| --- | --- |
| ✅ 四轮同向旋转 | 轮向 / ID / 线序全对,通过 |
| ❌ 一个轮反向 | 该轮机械装反或线序错,见 §0.4 |
| ❌ 对角两组各同向、组间反向 | tx_id 4/1/2/3 映射错位,查 §0.4 |
| ❌ 有轮不转 | 该轮 CAN/电调/离线,看 RTT `Motor lost` |

> **为什么用下挡而不是中挡**:云台未装时 offset ≈ −156.6°(垃圾),中挡一解锁就全速自转,
> 且跟随律的 wz 垃圾分量会污染转向观察;下挡 wz=+300 是常量,四轮呈现干净的自转组合特征。
>
> **前进/横移的驱动方向确认不在本轮**:下挡的恒定 wz 无法单独剥离 vx/vy;估计侧符号已由 §2
> 推车覆盖,驱动侧符号在云台装好后的 §4 平地平移复核。
>
> **架空时间不要太长**:确认完就回上挡,别让悬空的车自己"跑"下垫块。

## 2. 零力推车:逆解符号(≈15 分钟)

**目的**:验证 `EstimateSpeed()` 四轮逆解的符号与量级。这是后面所有速度判断的地基。

### 2.1 直行

1. 遥控右开关**上挡**(零力)→ 四轮停,手能推动;
2. **人推车向前走 2~3m**(匀速,约 0.5m/s),盯 `[chcal]` 的 `vx` 列;
3. 记录:`vx` 应为**正**,量级与实际推速相当(推 0.5m/s → `vx` 约 500 mm/s)。

### 2.2 横移

1. 人推车**向左横移 2m**,看 `vy`:应在一个方向上稳定为正;
2. 再向右横移,`vy` 应变号。

> 麦轮横移时辊子本身有滑移,`vy` 的**量级会偏乐观**(比实际位移速度大)。本轮只判**符号与单调性**,  
> 量级留到 P5 滑移补偿再标。

### 2.3 原地转(一次手转,两件事:est_wz 符号 + 跟随计划 F6 符号一致性)

1. 人推车**绕自身中心原地转一周**(像开门那样推一角,慢而匀),**同时**读两路:
   - `est_wz`(telemetry_chassis_fb 环的 extra 列)——看符号与实际转向的对应;
   - `Gyro[2]×RAD2DEG`(IMU 世界系角速度)——与 `est_wz` 做**同号对照**;
2. 记录一行:「从上往下看,逆时针推 → est_wz = 正/负;Gyro[2] = 正/负」。

> **两半结论,有效期不同**:
> - `est_wz` 侧符号 = 轮编码器 + 几何的事实,**永久有效**(小陀螺自转时 est_wz 的符号含义全靠它);
> - `Gyro[2]` 侧符号只在"IMU 临时固定在底盘"的当前安装态有效,**IMU 装回云台后须在 pitch-B1
>   轴向核验时重验**。
> - 若两者**异号**:跟随/小陀螺计划 P2 的 `(Gyro[2] − est_wz)` 阻尼输入会相减变相加(正反馈),
>   改造前必须先修符号约定,并记入 DEV 条目。
## 3. FOLLOW 模式可用性(≈3 分钟)

> **本轮(云台未装)直接跳过,预期就是失败**:中挡解锁 = 全速自转(见 0.5-b)。
> 此节保留给"云台装好后"复查用。

1. 车放平地,遥控右开关**中挡**,**不推杆**;
2. 观察 10 秒。

| 现象      | 结论                                                                   |
| ------- | -------------------------------------------------------------------- |
| 车完全静止   | ✅ FOLLOW 可用,继续第 4 步                                                  |
| 车缓慢均匀自转 | ❌ `offset_angle` 是垃圾值 → 云台零位没标 / yaw 电机不在线。**不要用中挡测平移**,改走 §4.1 路径 B |
| 车抖动/来回摆 | ❌ offset 在死区边缘反复穿越,同样先别用                                             |

## 4. 平地平移(≈15 分钟)

### 4.1 路径 A:FOLLOW 可用(推荐)

中挡(`wz≈0`),在平整地面上:

| 测试       | 操作                  | 判据                   |
| -------- | ------------------- | -------------------- |
| 前进 3m    | 右杆推到底保持,量终点与起点的横向偏移 | 偏移 <30cm(纯底盘相位,不含云台) |
| 后退 3m    | 同上                  | 同上                   |
| 左/右横移 3m | 右杆横推到底              | 偏移 <30cm             |

> 横移偏移天然比前进大(辊子侧滑),<50cm 可接受,先记基线。

### 4.2 路径 B:FOLLOW 不能用(云台没装好)

中挡不能用时,纯平移没有现成入口——`ROTATE` 会一直自转,且**带 +10° 平移偏置**(只在小陀螺模式生效)。

两个选择:

- **B1(推荐,要改代码)**:加一个 `CHASSIS_TEST_NO_FOLLOW` 开关,置 1 时把 `chassis_mode` 强制成  
  `CHASSIS_NO_FOLLOW`。3 行改动,以后修底盘都能复用;
- **B2(零改动)**:跳过第 4 步,只做第 2/5/6 步。**平移方向靠推车时的 `est_vx/est_vy` 符号判断**,  
  精度差但能挡住"装反"这类大错。

## 5. 小陀螺三档:计时法 + 三方比对(≈25 分钟)

**这一步是本轮的核心**,一次测三件事:力臂 340mm 对不对、轮径对不对、yaw 反馈对不对。

### 5.1 操作

1. 车放**空旷平地**,人退到 2m 外(它会漂,不会停在原地);
2. 地面上贴一个标记(胶带/瓶盖)作参考;
3. 右开关**下挡** → 车开始自转;等 2 秒转速稳定;
4. **计时转 10 圈**(3600°):手机秒表,从标记过参考点开始,数到第 10 次回到参考点停;
5. 同时读 `[chcal]` 的 `wz` 列(逆解),记录;
6. **重复 3 次取平均**;
7. 若条件允许,**手机架高俯拍 10 秒**,事后数圈数(比秒表准,能避开反应时间误差)。

> 每档之间**让车停 30 秒**再换,避免电池电压下降影响转速(电压降 → 转速降,会被误判成几何错)。

### 5.2 怎么改档位

**目前没有运行时入口**:`chassis.c:293` 是 `chassis_cmd_recv.wz = CHASSIS_ROTATE_SPEED;`,写死的宏。  
要跑 100/200/300 三档,只能改 `CHASSIS_ROTATE_SPEED` 重编重烧三次(每次约 5 分钟)。

> 如果嫌烦,可以让固件里加一个自动扫掠模式(每档 2~3s 自动递增、正反交替、同时 `[chcal]` 打点),  
> 一次烧录拿全数据。这是临时标定专用的代码,和当年 GM6020 自检同一套路。

### 5.3 三方比对(核心判据)

| 来源      | 读什么                    | 性质                              |
| ------- | ---------------------- | ------------------------------- |
| **计时法** | 3600° / t              | **唯一真值**,与代码几何无关                |
| **逆解**  | `[chcal]` 的 `wz`       | 依赖力臂 340mm / 轮径 / `WHEEL_RATIO` |
| **指令**  | `CHASSIS_ROTATE_SPEED` | 应等于实测,若不等说明换算链有问题               |

> **全部比大小,先取绝对值**。`ω_joint = −ω_chassis`(方向相反),坐标系里的负号不要带进比对。

| 现象                        | 结论                  | 查哪里                                                                                      |
| ------------------------- | ------------------- | ---------------------------------------------------------------------------------------- |
| 三者都 ≈ 指令                  | ✅ 力臂修正、轮径、逆解全对      | 通过                                                                                       |
| 逆解 ≠ 计时法,但指令 ≈ 计时法        | 逆解公式有问题             | 查 `EstimateSpeed` 的 `LF_CENTER` / `WHEEL_RATIO`                                          |
| 指令 ≠ 计时法,但逆解 ≈ 计时法        | 指令到轮速的换算错           | 查 `MecanumCalculate`                                                                     |
| 三者都 ≠ 理论值(如指令 300 实测 250) | **几何错**:力臂/轴距/轮距/轮径 | 查 `WHEEL_BASE=500`、`TRACK_WIDTH=460`、`RADIUS_WHEEL=75`。**不要调 `CHASSIS_ROTATE_SPEED` 去凑** |
| 实测转速比理论**高**很多            | 力臂被低估               | 同上                                                                                       |

**理论预期(按当前几何)**

| 档位  | 应有转速   | 转子 RPM |
| --- | ------ | ------ |
| 100 | 100°/s | 1433   |
| 200 | 200°/s | 2866   |
| 300 | 300°/s | 4299   |

### 5.5 启停瞬态建档(跟随/小陀螺计划 P3 的对照基线,≈10 分钟)

1. 下挡进/出各 3 次(进出之间隔 30 s,防电池压降与过热);
2. Ozone 看 `telemetry_chassis_fb` 的 `est_wz`(extra 列)与四轮 `measure.real_current`;
3. 记录:启动瞬间 est_wz 爬升超调量、四轮电流峰值、到稳态时间;退出同理。

> 这是跟随/小陀螺优化计划 P3(wz 斜坡)的**对照基线**,数据存 `.Doc/data/`。
> **装云台后转动惯量大增,这条基线必须重测**——本条空载数据只用于流程演练与回归对照。

### 5.6 温升(≈10 分钟)

连续小陀螺 300 档 60 s,Ozone 盯四轮 `measure.temperature`:判定 <50℃,记入 §7.2 温度行。

## 6. 极限叠加(≈10 分钟)

1. 下挡(小陀螺)持续自转;
2. 同时把右杆**推到底**(平移 1500mm/s);
3. 观察:车是否明显变慢、是否开始跑偏、有没有异响。

| 现象     | 含义                                                                              |
| ------ | ------------------------------------------------------------------------------- |
| 自转明显变慢 | 触了 6000RPM 削顶(自转 300 + 平移 1500 时 `vt_lf` 约 41,000 deg/s > 36,000 上限),属正常,记下触发组合 |
| 跑偏加重   | `CHASSIS_TRANSLATE_BIAS_ANGLE=10°` 是固定偏置,高速档本来就不够,留给 P5                         |
| 冲击/异响  | 立刻停,查机械                                                                         |

> 这一步只记录,**不调参**。削顶是物理上限,调参救不了,只能降指令。

## 8. 排查表

| 现象                            | 最可能原因                       | 处置                                                |
| ----------------------------- | --------------------------- | ------------------------------------------------- |
| 某个轮子完全不动                      | 该轮 CAN 线/电调/ID 冲突           | 看 RTT 有没有该 ID 的 `Motor lost`;查 tx_id 4/1/2/3 是否重复 |
| 四个轮子都不动                       | 底盘任务没跑 / 遥控没在线 / 模式是零力      | 看 `[chcal]` 有没有在打(打了说明任务在跑);确认右开关不在上挡             |
| 前进跑偏严重                        | 某轮装反 / 轮径不一致 / 地面不平         | 回第 1 步架空复查                                        |
| 小陀螺转速远低于指令                    | 触 6000RPM 削顶 / 电压低 / 几何错    | 先看电池电压,再看 `vt_lf` 是否被限幅                           |
| 小陀螺转速偏高                       | 力臂被低估(几何错)                  | 查 `WHEEL_BASE/TRACK_WIDTH`                        |
| `[chcal]` 全是 0                | `EstimateSpeed` 没被调用 / 电机离线 | 确认第四轮都有反馈                                         |
| `[chcal]` 的 `gz` 恒 0          | 云台在世界系静止(正常)                | **自转工况下 `gz` 不能当底盘转速参照**,这是设计事实                   |
| RTT 被 `CAN Send FIFO full` 刷屏 | 台架 CAN 无带电节点(无 ACK)         | 全车上电齐全后消失,否则查 CAN 终端电阻                            |
