## 1. 目标与非目标

### 1.1 目标

1. 让敌方自瞄(尤其"锁中心 + 按周期延迟击打"的反小陀螺)在 0.5~1.5 s 的观测窗口内**无法稳定预测**我方装甲板的出现时刻。
2. 不牺牲自身射击精度:变速期间云台仍能稳定打静止靶/移动靶。
3. 不突破机械、电流、功率边界;所有新行为可一键回退到恒速 300 deg/s
   (运行期键鼠 C 切换,DEV-20261125-08;编译期仍可 `CHASSIS_SPIN_VARY_EN=0` 整体回退)。

### 1.2 非目标

- 不追求"完全不可命中"。小陀螺只是降低命中率,不提供免疫。
- 不做基于视觉的"被瞄准检测":下位机拿不到可靠的被瞄准信号。
- 不改云台自瞄、不改发射、不改跟随/回中模式。
- 不在本阶段做强化学习/在线优化:样本量不够,且不可解释。

## 2. 事实基础(先于方案)

### 2.1 本车现状

- `chassis.c` 的 `case CHASSIS_ROTATE` 只有一句 `chassis_cmd_recv.wz = CHASSIS_ROTATE_SPEED;`,恒速 300 deg/s,无变速、无反转、无随机。
- `chassis_task` 200 Hz,`dt_ms` 可直接用于轨迹积分。
- `chassis_ramp_to(cur, target, accel, dt)` 已存在(`chassis_kinematics.c`),可作为角加速度限幅器。
- `CHASSIS_FOLLOW_GIMBAL_YAW` 分支**刻意不给 wz 加斜坡**(2026-11-16 实测:斜坡拖慢刹车,反摆 +22.2 deg/s,已否决)。该结论只适用于跟随律,**不能外推到小陀螺轨迹**;小陀螺需要自己的 α 限幅,且只作用在 ROTATE 分支。
- 本车未接裁判/超电,`PowerControl()` 未调用。变速/反转的电流峰值**没有闭环功率保护**,只能靠 α 限幅 + 电流阈值兜底。
- 工程内无现成 RNG;可用 DWT 时基 + xorshift32,种子混入上电抖动。

### 2.2 敌方自瞄的预测链(决定怎么打)

| 环节 | 典型做法 | 被什么破坏 |
|---|---|---|
| 装甲板识别 | 深度学习/传统灯条 | 转速过高导致运动模糊、漏检 |
| 状态估计 | `[θ, ω]` 或 `[x, y, vx, vy]` 匀速卡尔曼 | 角加速度持续存在 → ω 估计滞后 |
| 反小陀螺 | 锁旋转中心,按 `T = 2π/ω` 预测装甲板经过时刻 | ω 变化 → 相位漂移;反转/急停 → KF 重初始化 |
| 延迟补偿 | 按当前 ω 外推 60~120 ms | 转速突变 → 外推方向/幅度错误 |
| 开火判定 | 角度进入阈值 + 延迟击打 | 预测残差大于装甲板半宽即脱靶 |

结论:自瞄模型只有 2 维,**不需要复杂轨迹,只要让 ω(t) 持续有不可短窗辨识的角加速度**。

### 2.3 开源证据(截至 2026-11-24 可访问)

2. **西安电子科技大学 IRobot 2023 技术报告**:
   用随机数做"旋转速度的随机化、旋转时间的随机化、反转时间的随机化",目的是面对反小陀螺自瞄时延长存活时间。报告只给方法框图,未给具体范围。
3. **视觉侧反证**:
   - RM 社区视觉教程:反小陀螺的标准做法是"云台对准中心、不跟装甲板",前提是"小陀螺基本上匀速转动"。
   - IMCA 自瞄文档:敌人急停会让"卡尔曼重新初始化",云台甩飞。

## 3. 设计思想:从钱学森弹道到角速度轨迹

钱学森弹道的价值不是"弹道"形状,而是让拦截方的**预测模型维度不够**:非周期、分段跳跃、末段强机动。映射到小陀螺:

| 弹道特性 | 角速度轨迹映射 | 工程手段 |
|---|---|---|
| 助推段 | 从巡航加速到高速 | `SPIN_BOOST`,+α 限幅 |
| 滑翔段 | 高速短时保持,叠加多尺度调制 | `SPIN_GLIDE`,准周期正弦叠加 |
| 跳跃/再入 | 减速或直接反转 | `SPIN_BRAKE` / `SPIN_REVERSE`,-α 限幅 |
| 末段不可预测 | 段长/符号/幅度由真随机决定 | xorshift32 + 上电熵源 |

**不照搬的地方**:弹道有三维空间和气动升力,小陀螺只有绕竖直轴的 ω;不要试图用"跳跃高度"之类隐喻,最终都要落到 `ω(t)` 和 `α(t)` 上。

## 4. 方案对比与选型

| 方案 | 破匀速 | 可执行性 | 机械/功率风险 | 被统计风险 | 结论 |
|---|---|---|---|---|---|
| 恒速 300 | 无 | 最好 | 低 | 最高 | 现有基线,保留为回退档 |
| 固定阶梯(COD 式) | 中 | 好 | 低 | 中(固定 1.2 s 周期) | 作为 P1 基线 |
| 多尺度正弦叠加 | 中高 | 好 | 低 | 中(准周期长期可拟合) | 作为调制层,不单独用 |
| 随机段长 + 随机反转 | 高 | 中 | 中高 | 低 | **核心** |
| 纯白噪声 | 低(被低通/惯量滤掉) | 差 | 高 | 低 | 否决 |
| Logistic 混沌映射 | 高 | 中 | 中 | 低 | 可选随机源,不直接用混沌输出 |

**选定:分段状态机 + 多尺度调制 + 真随机事件 + α 限幅**,代号 `SPIN_JITTER`。

## 5. 算法设计

### 5.1 状态机

```
SPIN_IDLE ──进入ROTATE──> SPIN_CRUISE ──随机──> SPIN_BOOST ──> SPIN_GLIDE ──┐
                              │                                            │
                              ├──随机──> SPIN_BRAKE ──> SPIN_REVERSE ──────┤
                              │                                            │
                              └──────────────<── SPIN_RECOVER <───────────┘
```

| 状态 | 输出目标 | 持续时间 | 转移 |
|---|---|---|---|
| `SPIN_CRUISE` | `ω_cruise × (1 + m(t))` | 0.5~1.2 s 随机 | 40% BOOST / 35% BRAKE / 25% REVERSE |
| `SPIN_BOOST` | `ω_high` | 到速或 0.35 s 超时 | 必进 GLIDE |
| `SPIN_GLIDE` | `ω_high × (1 - 0.5·|m(t)|)` | 0.2~0.5 s 随机 | 回 CRUISE |
| `SPIN_BRAKE` | `ω_low` | 0.2~0.4 s | 回 CRUISE |
| `SPIN_REVERSE` | `-ω_reverse` | 0.6~0.9 s | 回 RECOVER |
| `SPIN_RECOVER` | `ω_cruise` | 到速或 0.8 s 超时 | 回 CRUISE |

约束:
- 连续两次反转之间至少 1.2 s(机械冲击/电流)。
- 不允许连续两次同向 BOOST(避免形成"加速-滑行"的固定节拍)。
- 进入 ROTATE 的沿重置状态机与随机相位,避免每次上车同一轨迹。

### 5.2 多尺度调制

```
m(t) = a1·sin(2π·f1·t + φ1) + a2·sin(2π·f2·t + φ2)
|m(t)| <= m_limit
```

- `f1 = 0.31 Hz`,`f2 = 0.83 Hz`:不可通约,避免明显周期。
- `a1 = 0.20`,`a2 = 0.10`,`m_limit = 0.30`。300×(1+0.30)=390,不顶 400 上限。
- `φ1/φ2` 每次进入 CRUISE 用随机数重置,防止长期相位可预测。
- 调制只作用在 CRUISE/GLIDE,不作用在 BOOST/REVERSE(避免削弱机动幅度)。

### 5.3 输出与限幅

```
ω_target = clamp(ω_state × (1 + m), ω_min, ω_max)
ω_out    = chassis_ramp_to(ω_out_prev, ω_target, α_max, dt)
```

- `α_max` 起始 800 deg/s²,实测后上限 1500。
- `ω_min = 180`,`ω_max = 350`(2026-11-26 从 400 降,DEV-20261126-16),`ω_reverse = 200`(已移除)。
- 反转段必须真正过零:`(300+200)/800 = 0.63 s`,故反转时长取 0.6~0.9 s;短于此只会减速,不构成反转。
- 输出仍走现有运动学逆解,不绕过 `chassis_cmd_recv.wz`。

### 5.4 随机源

- `xorshift32` 状态 = `DWT->CYCCNT ^ RTC->CNTL ^ 上电 ADC 噪声`(若 ADC 未启用则用两次 DWT 采样差)。
- 每局/每次上电不同;禁止编译期固定种子。
- 随机只用于:段长、状态转移、反转符号、相位重置。**不直接随机 ω**,否则电流和机械不可控。

## 9. 验证方案

### 9.1 台架(架空)

- 录 `est_wz`、四轮 `real_current`、IMU `gz/roll/pitch`。
- 阶跃/反转指令:上升时间、超调、电流峰值、反转完成时间。
- 判据:稳态跟踪误差 <10%;电流峰值 <恒速 2 倍;反转 <400 ms。

### 9.2 实车轨迹分析

- 60 s 匀速段 + 60 s 变速段,各录 IMU `gz`。
- 离线算自相关与 PSD:变速段的次峰 <0.5(恒速段应接近 1)。
- 检查无 50 Hz/100 Hz 电源干扰混入轨迹。

### 9.3 对抗验证

- 同一距离(3 m/5 m),用本车自瞄或开源自瞄录数据。
- 恒速 vs 变速各 20 发,统计命中率。
- 判据:变速命中率相对恒速下降 ≥30%;自身打静止靶命中率 ≥恒速的 85%。

### 9.4 静态闸门

`check_naming`、`check_comment_style`、`check_macros`、`check_macro_dups`、`check_source_lists`、`check_symbol_contract`、`check_macro_golden` 全 PASS(宏账本同步后)。

## 10. 风险矩阵

| 风险 | 触发条件 | 缓解 |
|---|---|---|
| 机械冲击/打滑 | 频繁反转、α 过大 | 最短反转间隔 1.2 s;α 从 800 起;`est_wz` 与指令偏差 >30% 持续 200 ms 则降频 |
| 电流/功率超限 | 高速段(反转已移除) | 模型预测限幅:目标 80W,超限压指令电流(二次解)+按比例压积分限幅(DEV-20261126-12/16);仍超先降 `MOD_LIMIT`/`HIGH_DPS` |
| 自身射击精度下降 | 底盘 roll/pitch 晃动 | 验收门槛 85%;晃动超标先降 α 再降转速 |
| 被统计 | 固定段长/固定符号 | 真随机种子;段长区间宽;相位重置 |
| 低速窗口 | BRAKE 段过长 | 低速段 ≤0.4 s,且只作为反转前过渡 |
| 规则风险 | 2027 规则对旋转的限制 | 已有规则手册在 `.Doc/`;实施前确认无新增限制 |
| 与跟随/回中冲突 | 模式切换残留 | 只在 `CHASSIS_ROTATE` 分支生效;进入沿重置;退出即 `wz=0` |

## 11. 明确不做

- 不做纯白噪声抖动:被底盘惯量和速度环滤掉,只增加电流冲击。
- 不做固定周期变速:对手统计几秒即可算出。
- 不做基于视觉的闭环躲避:下位机没有可靠目标方位。
- 不在 P0~P4 内改云台/发射/自瞄。

## 12. 已拍板的三个决定(2026-11-24)

1. **高速档取 350**:390 地面实测约 100W,2026-11-26 从 400 降到 350(DEV-20261126-16)。
2. **允许反转,但先温柔**:反转目标 -200 deg/s,`α=800 deg/s²`,时长 0.6~0.9 s,最短间隔 1.5 s;目的是先验证机械/电流,再考虑加深。
3. **多尺度正弦保留测试**:`a1/a2=0.20/0.10`,总限幅 0.30;若实车云台晃动明显,可先降到 `a1/a2=0.12/0.06`。
