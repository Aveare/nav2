## C. 落地映射(与方案批次对应)

**已采纳进方案(勿重复规划)**:
- 三件套(clang-format/clang-tidy/cppcheck)→ 附录E + T15(B1 交付配置、B1b 执行,G11 等价闸门)。
- 看门狗全员心跳监督 → diag 必活/可选集合 + G9 自动化(修"任务卡死不触发 IWDG"的真实安全差距)。
- 主机测试收敛 Unity/Ceedling → B0 host 整链 harness;扩展对象 heat_guard/ramp/kinematics。
- 分层依赖审计 → §3 目录树 + T01 扫描(framework 0 RTOS include / h* 句柄标识符扫描)。

**解冻后候选(按性价比)**:① IWDG 全任务心跳(方案已覆盖,随 diag 落地);② XDU 辨识流程替代手工重力/摩擦拟合(届时先复核 gimbal-tool-suite 活跃度);③ AX650 侧对接 rm_vision 系;④ 消息中心多槽演进(仅当事件型需求出现;OneMessage 已停滞,届时优先自研)。

**无需对标(开源界领先,保持不动)**:热量守卫、bsp_fault 留痕、循环 DMA 串口、重构闸门体系。
