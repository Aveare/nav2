## 维护规则

- 新增文档先决定归属:`plan` / `spec` / `detail` / `guide` / `history`,并在本表登记一行;
- 引用文档写**带目录的路径**(如 `.Doc/spec/本车调参结论.md`),不要只写文件名;
- `history/` 只追加,不修改;过期计划移入 `history/` 而不是删除(删除前先确认 `git log --diff-filter=D` 可追溯);
- 路径一致性可用 `python tools/refactor_gate.py check-links` 自检。
