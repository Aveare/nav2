# 桌面建图与中心点一键脚本

本目录用于现场完成一套 `test` 地图，并在同一张地图上分别记录红方、蓝方出生点。地图只建并保存一次，两个出生点各点击一次。所有步骤均为可执行 `.sh`，从文件管理器运行时会自动打开终端。

## 执行顺序

| 顺序 | 脚本 | 操作结果 |
|---:|---|---|
| 00 | `00_查看执行顺序.sh` | 查看本说明 |
| 01 | `01_建图前安全检查.sh` | 检查 MID360S、STM32、ROS 2 和冲突进程 |
| 02 | `02_启动实车扫描建图.sh` | 启动雷达、动态大 yaw、SLAM Toolbox 和建图 RViz |
| 03 | `03_保存为test地图.sh` | 备份旧地图并保存 `/home/rm/maps/test.yaml` 和地图图像 |
| 04 | `04_停止扫描建图.sh` | 停止建图、雷达、串口桥和建图 RViz |
| 05 | `05_启动test地图定位与RViz.sh` | 用 `test.yaml` 启动定位和带 Publish Point 的 RViz |
| 06 | `06_RViz点击并保存test中心点.sh` | 可选：保存 `/home/rm/maps/test_center.csv` |
| 06A | `06A_RViz点击并保存红方出生点.sh` | 在 RViz 点击一次，保存 `/home/rm/maps/test_red_spawn.csv` |
| 06B | `06B_RViz点击并保存蓝方出生点.sh` | 在 RViz 点击一次，保存 `/home/rm/maps/test_blue_spawn.csv` |
| 07 | `07_显示test中心点.sh` | 在 RViz 显示橙色中心箭头和 `CENTER` 标签 |
| 08 | `08_停止定位和中心点显示.sh` | 停止中心点显示、定位、雷达、串口桥和 RViz |
| 09 | `09_核对test地图和中心点文件.sh` | 最终核对地图和红、蓝出生点是否配套存在 |

任一步出现 `[FAIL]` 时停止，不要跳过失败步骤继续运行。

## 红、蓝出生点点击方法

执行步骤 05 后保持定位终端运行。先执行步骤 06A 保存红方出生点，再执行步骤 06B 保存蓝方出生点。每个脚本看到等待提示后：

1. 回到 RViz。
2. 确认 **Global Options → Fixed Frame** 为 `map`。
3. 点击顶部 **Publish Point**。
4. 在对应颜色的出生位置单击一次。
5. 回到脚本终端，确认出现“出生点已保存”。

不要用 **2D Pose Estimate** 记录中心点，它会改变机器人定位。不要用 **Nav2 Goal**，它会发起导航任务。

红方默认车头方向是 `map` 正 X，即 `yaw=0°`；蓝方默认朝 `map` 负 X，即 `yaw=180°`。地图坐标方向不同时，可从终端覆盖默认值：

```bash
cd /home/rm/Desktop/建图与中心点
RED_SPAWN_YAW_DEG=90 ./06A_RViz点击并保存红方出生点.sh
BLUE_SPAWN_YAW_DEG=-90 ./06B_RViz点击并保存蓝方出生点.sh
```

## 安全设置

- 建图和定位均固定 `enable_drive=false`。
- 固定 `enable_autoaim=false`、`start_navigation=false`、`start_async_workflow=false`。
- 脚本不会发布有效底盘速度，也不会自动导航到中心点。
- STM32 串口只能由一个进程占用。若步骤 01 检测到串口联调桥，请先停止串口联调。
- 步骤 02 运行期间通过下位机遥控或人工方式缓慢移动机器人。

## 自动备份

覆盖前会保存旧文件：

```text
/home/rm/maps/history/test_before_日期_时间/
/home/rm/maps/history/center_before_日期_时间/
```

脚本不会直接删除旧地图或旧中心点。

## 文件对应关系

```text
/home/rm/maps/test.yaml
/home/rm/maps/test.pgm 或 test.yaml 中 image 指定的图像
/home/rm/maps/test_red_spawn.csv
/home/rm/maps/test_blue_spawn.csv
/home/rm/maps/test_center.csv（可选）
```

出生点和可选中心点都属于当前地图的 `map` 坐标系。只要重新保存地图，就必须重新执行步骤 06A 和 06B，不能继续使用旧地图的出生点坐标。
